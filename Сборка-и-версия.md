# Сборка и версия

Как поменять номер версии и собрать установщики **Маразматички** и **Склерозника**.

Пишите в PowerShell из папки проекта: `C:\Projects\Marazmati4ka`.

Автообновления в программе нет. Новая версия попадает на компьютер только так: собрали свежий `.exe` → закрыли старую программу → поставили новый установщик поверх.

---

## Две программы из одного проекта

| | Маразматичка | Склерозник |
|---|---|---|
| Команда сборки | `npm run desktop` | `npm run desktop:empty` |
| Файл установщика | `dist-desktop\Marazmati4ka-Setup-X.Y.Z.exe` | `dist-desktop\Skleroznik-Setup-X.Y.Z.exe` |
| Что внутри | программа **и** ваши текущие заметки, `docs/` и картинки | только пустая программа |
| Для кого | себе | другому человеку, с чистого листа |
| Папка данных после установки | `%APPDATA%\Marazmati4ka\notebook\` | `%APPDATA%\Skleroznik\notebook\` |
| Порт | 3005 | 3007 |

Это две разные программы. Их можно держать установленными сразу: они не делят заметки и не мешают друг другу.

Номер версии у обеих один и тот же. Он берётся из `package.json`. Если там `0.2.1`, файлы будут `Marazmati4ka-Setup-0.2.1.exe` и `Skleroznik-Setup-0.2.1.exe`.

---

## Как поменять версию

Меняйте номер **до** сборки. Иначе установщик назовётся старым номером, хотя внутри уже новый код.

### 1. Выберите следующий номер

Три цифры: `старшая.средняя.правка`, например `0.2.1`.

- Поправили ошибку, ничего нового для пользователя — поднимите последнюю: `0.2.1` → `0.2.2`.
- Добавили возможность (своя модель, заглушка обложки, поле ссылки) — среднюю: `0.2.1` → `0.3.0`.
- Ломаете совместимость специально — старшую: `0.3.0` → `1.0.0`. Так почти не делают, пока сами не решите.

Не пропускайте номер «на глаз». Смотрите, что уже написано в `package.json` в строке `"version"`.

### 2. Пропишите номер в файлах

**Обязательно**

1. `package.json` — строка `"version": "0.2.1"` → ваш новый номер.
2. `package-lock.json` — то же число в **двух** местах в самом верху файла:
   - `"version": "0.2.1"` сразу после `"name"`;
   - и ещё раз внутри блока `"packages"` → `""` → `"version"`.

Остальные `"version"` в `package-lock.json` не трогайте: это версии чужих библиотек.

**Желательно, чтобы люди не путались**

3. `README.md` — фраза `Версия **0.2.1**`.
4. `CHANGELOG.md` — блок `## Unreleased` превратите в датированный выпуск, например:

```md
## 0.2.2 — 2026-08-16

### Added

- …

### Fixed

- …
```

Новый пустой `## Unreleased` можно оставить сверху для следующих правок.

Другие файлы (`desktop/flavors/*.json`, `electron-builder.yml`) номер версии не хранят. Их менять не нужно.

### 3. Проверьте

Откройте `package.json` и убедитесь, что видите именно новый номер. Потом собирайте.

## Что нужно для сборки

- Windows (установщик собирается только под Windows x64).
- Node.js **22 или новее**. Проверка: `node -v`. На Node 24 уже собирали.
- Один раз в папке проекта: `npm install`.
- Закройте Маразматичку и Склерозник, если они запущены. Иначе сборщик может не перезаписать файлы в `dist-desktop\`.
- Запускайте команды **через обычный Node**, не из окна Electron и не из чужой среды, где `node` указывает не туда. Сборщик копирует в установщик тот самый `node.exe`, которым вы запустили команду.

Сборка занимает несколько минут. Первый раз дольше: Next.js собирает сайт, потом electron-builder пакует установщик.

## Собрать Маразматичку

В установщик попадёт **снимок ваших данных на момент сборки**: папка `docs/`, файл `data\notebook.db` и картинки из `data\media\`. Это нужно, чтобы на чистом компьютере сразу открылась ваша библиотека. На компьютере, где программа уже стояла, этот снимок **не затирает** уже живущие заметки — см. раздел про обновление.

1. Закройте приложение.
2. Сохраните файлы, которые должны войти в программу.
3. В корне проекта:

```powershell
npm run desktop
```

4. Дождитесь строки вроде `Установщик: …\dist-desktop\Marazmati4ka-Setup-0.2.2.exe`.
5. Готовый файл лежит в папке `dist-desktop\`.

Не выкладывайте этот `.exe` в открытый git и не кидайте незнакомым людям: внутри ваша база и картинки.

## Собрать Склерозник

В установщик **не** кладутся ваши заметки, `docs/` и база. Получается пустой блокнот: другие типы и области, своя папка данных, порт 3007.

1. Закройте приложение.
2. В корне проекта:

```powershell
npm run desktop:empty
```

3. Файл: `dist-desktop\Skleroznik-Setup-0.2.2.exe`.

Этот установщик можно отдавать другому человеку и выкладывать в GitHub Releases.

## Собрать оба подряд

Номер версии один, менять его между сборками не нужно.

```powershell
npm run desktop
npm run desktop:empty
```

Первая команда заново собирает сайт (`next build`). Вторая сделает то же самое ещё раз — это нормально, просто дольше.

Если только что собрали одну вариацию и сразу хотите вторую, можно сэкономить время и **не** пересобирать сайт:

```powershell
npm run desktop
node scripts/pack-desktop.mjs --flavor=skleroznik --reuse
```

или наоборот:

```powershell
npm run desktop:empty
node scripts/pack-desktop.mjs --flavor=marazmati4ka --reuse
```

`--reuse` берёт уже собранный сайт из `desktop\payload\app`. Используйте только если после предыдущей сборки код не меняли. Сомневаетесь — запускайте обычные `npm run desktop` и `npm run desktop:empty`.

Обе команды пишут в одну папку `dist-desktop\`. Старые `*-Setup-*.exe` с другим номером сами не удаляются. Новый файл с тем же именем перезапишется.

## Что лежит в `dist-desktop\`

| Файл | Зачем |
|---|---|
| `Marazmati4ka-Setup-X.Y.Z.exe` | установщик Маразматички |
| `Skleroznik-Setup-X.Y.Z.exe` | установщик Склерозника |
| `win-unpacked\` | распакованная последняя сборка, для проверки без установки |
| `latest.yml` | служебный файл сборщика, программа его сама не качает |

В git эта папка не должна попадать.

## Первая установка

1. Запустите нужный `*-Setup-X.Y.Z.exe`.
2. Это обычный мастер Windows, не «одна кнопка». Можно оставить папку по умолчанию.
3. Появятся ярлыки на рабочем столе и в меню Пуск.
4. Откройте программу. Первый запуск чуть дольше: поднимается встроенный сервер.

**Маразматичка в первый раз** копирует в профиль снимок библиотеки из установщика.

**Склерозник в первый раз** открывается пустым. Типы и области — универсальные: заметка, список, идея, личное, работа и так далее.

## Обновление уже установленной программы

1. Закройте окно блокнота. Проверьте в диспетчере задач, что не осталось `Marazmati4ka.exe` / `Skleroznik.exe`.
2. Запустите **новый** установщик той же вариации (`Marazmati4ka-Setup-…` на Маразматичку, `Skleroznik-Setup-…` на Склерозник).
3. Ставьте в ту же папку, что и раньше. Удалять старую установку не нужно.
4. Откройте программу и проверьте, что новые правки на месте (например поле своей модели в настройках).

Обновление меняет **только программу**. Заметки, зеркала `.md` и картинки живут в профиле Windows и не затираются.

Папки данных:

- Маразматичка: `C:\Users\<вы>\AppData\Roaming\Marazmati4ka\notebook\`
- Склерозник: `C:\Users\<вы>\AppData\Roaming\Skleroznik\notebook\`

В самой программе: меню **Файл → Папка данных**.

Удаление через «Программы и компоненты» программу снимает, папку с заметками **не** трогает. Так задумано.

## Частые ошибки

**Собрали, а в установленном окне всё по-старому.**  
Вы смотрите старую установку. Нужно закрыть программу и прогнать новый `.exe`. Правки из папки проекта сами в установленное окно не переезжают.

**Номер в имени файла старый.**  
Забыли поменять `"version"` в `package.json` до сборки. Поменяйте и соберите ещё раз.

**Сборка упала с текстом про Node / `node.exe`.**  
Команду запустили не тем интерпретатором. Откройте обычный PowerShell, проверьте `node -v` и повторите.

**Сборка ругается, что нет `notebook\node_modules\next`.**  
Пакет собрался криво. Удалите папки `desktop\payload` и `dist-desktop`, затем снова `npm run desktop` без `--reuse`.

**В Склерозник попали ваши заметки.**  
Вы запускали `npm run desktop` вместо `npm run desktop:empty`. Пересоберите правильной командой и отдайте уже новый файл.

**В Маразматичке после обновления пропали заметки.**  
Так быть не должно, если данные уже лежали в AppData. Откройте **Файл → Папка данных** и посмотрите, на месте ли `data\notebook.db`. Если ставили в другой профиль Windows или другую учётку — это другая папка AppData.

**Хотите проверить без установки.**  
Можно запустить `dist-desktop\win-unpacked\Marazmati4ka.exe` (или `Skleroznik.exe` после сборки Склерозника). Это последняя собранная вариация: папка `win-unpacked` общая и перезаписывается каждой сборкой.

## Короткий чеклист выпуска

1. Правки сохранены, программа закрыта.
2. Номер версии прописан в `package.json` и вверху `package-lock.json`.
3. В `CHANGELOG.md` есть блок с этим номером и датой.
4. В `README.md` обновлена строка «Версия».
5. `npm run desktop` — себе.
6. `npm run desktop:empty` — если нужен Склерозник.
7. Закрыть старое приложение → поставить новый Setup → открыть и глянуть глазами.
8. Установщик Маразматички никуда публично не выкладывать. Склерозник при желании — в Releases.
