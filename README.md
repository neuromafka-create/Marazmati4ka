# Marazmati4ka

Личный блокнот для промптов, инструкций, подборок и шпаргалок.

Это не облачная «память агента» и не соцсеть. Записи живут у вас: карточка в SQLite (как элемент инфоблока в Битриксе) и параллельный Markdown-файл в `docs/`. Интерфейс читает и пишет базу; файл — зеркало для git и внешнего редактора.

Версия **1.5.0**. Тема по умолчанию — тёмная графитовая, в шапке переключатель на светлую.

Есть две сборки:

| | Marazmati4ka | Склерозник |
|---|---|---|
| Для кого | вы, со своим архивом | подруга / другой человек, с нуля |
| Заметки в установщике | да, ваши `docs/` и база | можно выбрать свою папку с `.md`/`.txt` |
| Справочники | промпт, инструкция, графика, агенты… | заметка, список, идея, личное, работа, дом… |
| Папка данных | `%APPDATA%\Marazmati4ka\` | `%APPDATA%\Skleroznik\` |
| Порт | 3005 | 3007 |

Обе программы можно держать открытыми сразу.

## Что умеет

- Библиотека карточек с обложками, поиском и фильтрами по **типу** и **области**
- Сортировка: алфавит, дата создания, дата изменения
- На карточке при наведении: карандаш (правка) и корзина (в корзину)
- Просмотр: Markdown, копирование промпта, галерея
- Полноразмерные картинки во всплывающем слое; стрелки и ←/→, если их несколько
- Редактор: заголовок, тип, несколько областей, источник, текст; новый тип или область можно добавить сразу в форме
- Панель форматирования: жирный, курсив, заголовки, списки, цитата, код, ссылка; вкладка «Как будет»
- Картинки: диалог файла и **Ctrl+V**; в правке можно сменить роль (обложка / результат / референс / файл)
- Видео из файла (mp4, webm, mov, до 500 МБ) играется в галерее заметки. Обложкой ролик не становится
- К заметке можно прикрепить PDF (до 50 МБ): список в конце карточки, не в галерею картинок
- Удаление картинки крестиком
- Блоки кода: перенос, язык, «Копировать»
- Настройки: Hubris (партнёрская ссылка), своя модель, справочники типов/областей, картинка по умолчанию для карточек без обложки
- Меню «Справка → О программе»: версия и ссылка на обновление, если на GitHub есть новее
- Генерация иллюстрации к записи (с референсами: файл, Ctrl+V, «Из записи»)
- Корзина: запись не стирается, `active = 0`, зеркало уезжает в `_trash/`
- Первый запуск импортирует `.md` из `docs/`, если база пустая

## Требования

- **Node.js 22+** (нужен встроенный `node:sqlite`; проверялось на Node 24)
- npm
- Windows, macOS или Linux (браузерный режим)
- Windows x64 — для установщика

База — файл `data/notebook.db`. PostgreSQL не нужен.

## Запуск в браузере

```bash
git clone https://github.com/neuromafka-create/Marazmati4ka.git
cd Marazmati4ka
npm install
npm run dev
```

Откройте [http://localhost:3005](http://localhost:3005).

```bash
npx next dev --port 3010   # другой порт
npm run build && npm start # постоянный сервер, тоже 3005
```

## Десктоп (Windows)

```bash
npm install
npm run desktop        # Marazmati4ka-Setup — ваша библиотека внутри
npm run desktop:empty  # Skleroznik-Setup — блокнот для другого человека
```

Файлы появятся в `dist-desktop/`. В git они не лежат: полный установщик содержит личную базу, его собирают у себя. Склерозник можно выкладывать в [Releases](https://github.com/neuromafka-create/Marazmati4ka/releases): при установке спрашивает папку с `.md`/`.txt` и копирует их в блокнот (исходники не трогает). Поле можно оставить пустым.

Сборку запускайте на Windows тем же Node 22+, что и `npm run dev` — его `node.exe` упаковывается в установщик.

Установщик ставит ярлыки на рабочий стол и в меню Пуск. База и зеркала живут в AppData и при удалении программы **не стираются**. Меню «Файл → Папка данных» открывает эту папку.

Обновление установщика меняет только программу. Уже существующие заметки, `docs/` и картинки в AppData не затираются. Ссылки на источники открываются во внешнем браузере; если страница всё же открылась в окне блокнота — «Файл → Назад» или Alt+←.

Если при закрытии окна всплывало «Сервер блокнота завершился (4294967295)» — это была ложная ошибка при остановке сервера, с 0.2.0 её нет.

## Как устроено хранение

Две параллельные сущности, канон — **база**.

| | База (`notes`) | Файл `.md` |
|---|---|---|
| Роль | элемент инфоблока: id, поля, полный текст | зеркало на диске |
| Обязателен | да | нет |
| Кто главный | да | нет |
| Зачем | интерфейс, поиск, фильтры, корзина | git, Obsidian, бэкап папки |

- `/n/42` читает SQLite, не диск.
- После сохранения пишется `docs/<тип>/<основная-область>/<slug>.md`.
- Если файл не записался, элемент всё равно жив.
- Файл без элемента в библиотеке не виден, пока его не импортировали.
- При расхождении побеждает база.

Картинки и видео: запись в `files` + байты в `data/media/<id>/`. В тексте ссылка `![](/media/184)`, не base64. Ролик в текст не вставляется, его смотрят в галерее.

В десктопе корень данных задаётся `MARAZ_ROOT` (профиль пользователя), не папка установки.

Подробности — в [DESIGN.md](./DESIGN.md).

## Нейросеть (Hubris)

В **Настройках** подключается [Hubris](https://hubris.pw/docs/quickstart): OpenAI-совместимый шлюз.

1. [Регистрация](https://hubris.pw/sign-in)
2. Ключ `sk-gw-…` в [API-ключах](https://hubris.pw/keys) — показывается один раз
3. Баланс от 300 ₽ в [Биллинге](https://hubris.pw/billing)
4. Вставить ключ → «Сохранить» → «Проверить связь»

Ключ лежит только в локальной SQLite, в интерфейс целиком не возвращается. URL по умолчанию: `https://api.hubris.pw/v1`.

Дальше в просмотре и правке — «Нарисовать иллюстрацию». Референсы (лицо, поза) **не** подставляются сами: их добавляют файлом, Ctrl+V или кнопкой «Из записи». Результат сохраняется как обычная картинка заметки.

## Типы и области

Правятся в **Настройках** (`/settings`).

**Marazmati4ka:** Промпт, Инструкция, Подборка, Заметка, Шпаргалка.  
Области: Графика, Видео, Тексты, Маркетинг, Аналитика, Агенты, Код, Инструменты, Учёба, Бизнес.

**Склерозник:** Заметка, Список, Идея, Инструкция, Ссылка.  
Области: Личное, Работа, Дом, Учёба, Здоровье, Финансы, Разное.

Код (slug) идёт в путь файла; название — на экране. У записи несколько областей. Фильтр «Графика» показывает все заметки, где эта область есть. Первая выбранная — основная для зеркала. Удаление занятого пункта спросит, куда перенести записи.

## Импорт архива

В репозитории `docs/` — разобранный архив (~580 markdown-файлов).

При **первом** запуске, если база пустая, сервер обходит `docs/**/*.md`. Вшитые `data:image/…` вытаскиваются в `files`.

Повторный импорт не затирает уже изменённые карточки. Новый файл без записи: `POST /api/import` или `GET /api/import`.

## Структура репозитория

```
app/                      страницы и API (Next.js App Router)
  page.tsx                библиотека
  n/[id]/                 просмотр и /edit
  new/                    черновик → редактор
  settings/               Hubris и справочники
  media/[id]/             картинки /media/<id>
  api/                    notes, files, taxons, settings, import
components/               Library, Editor, NoteView, Lightbox, …
lib/                      SQLite, Hubris, таксономия, пути
desktop/                  оболочка Electron, вкусы, иконки
scripts/pack-desktop.mjs  сборка NSIS
docs/                     зеркала заметок
data/                     notebook.db и media/ — не в git
DESIGN.md                 проектные решения
```

## Полезные адреса

| Путь | Что |
|---|---|
| `/` | библиотека |
| `/?q=…&type=prompt&domain=image&sort=title&dir=asc` | поиск, фильтры, сортировка |
| `/n/42` | просмотр |
| `/n/42/edit` | правка |
| `/new` | новая запись |
| `/settings` | нейросеть и справочники |
| `/media/184` | файл картинки |

## Чего нет в 1.4

Аккаунты, избранное, связанные карточки, деплой на Vercel (нужны диск и файл БД). Для своего сервера — Node-процесс на VPS/Fly с томом на `data/` и `docs/`.
