# Marazmati4ka

Личный веб-блокнот для промптов, инструкций, подборок и шпаргалок по ИИ.

Это не облачная «память агента» и не соцсеть. Записи живут у вас: карточка в SQLite (как элемент инфоблока в Битриксе) и параллельный Markdown-файл в `docs/`. Интерфейс читает и пишет базу; файл — зеркало для git и внешнего редактора.

Версия **0.1.0**. Тема по умолчанию — тёмная графитовая, в шапке переключатель на светлую.

## Что умеет

- Библиотека карточек с обложками, поиском и фильтрами по **типу** и **области**
- Сортировка: алфавит, дата создания, дата изменения (по возрастанию и убыванию)
- Быстрый переход в правку — карандаш на карточке при наведении
- Просмотр заметки: Markdown, копирование промпта, галерея картинок
- Полноразмерный просмотр картинки во всплывающем слое (клик по превью)
- Редактор: заголовок, тип, несколько областей, источник, текст
- Картинки: диалог файла и вставка **Ctrl+V** (скриншот / буфер)
- Удаление лишней картинки крестиком в галерее
- Блоки кода: перенос по ширине, подпись языка (`js`, `bash`, `text`…), кнопка «Копировать»
- Справочники типов и областей: создание, правка, удаление с переносом записей
- Корзина: запись не стирается, `active = 0`, зеркало уезжает в `_trash/`
- Первый запуск импортирует все `.md` из `docs/` в базу

## Требования

- **Node.js 22+** (нужен встроенный модуль `node:sqlite`; проверялось на Node 24)
- npm
- Windows, macOS или Linux

Отдельный сервер PostgreSQL не нужен. База — файл `data/notebook.db`.

## Запуск

```bash
git clone https://github.com/neuromafka-create/Marazmati4ka.git
cd Marazmati4ka
npm install
npm run dev
```

Откройте в браузере: [http://localhost:3005](http://localhost:3005)

Порт **3005**, потому что 3000 часто занят другими проектами. Сменить:

```bash
npx next dev --port 3010
```

Сборка для постоянного сервера:

```bash
npm run build
npm start
```

`npm start` тоже слушает 3005.

## Как устроено хранение

Две параллельные сущности, канон — **база**.

| | База (`notes`) | Файл `.md` |
|---|---|---|
| Роль | элемент инфоблока: id, поля, полный текст | зеркало на диске |
| Обязателен | да | нет |
| Кто главный | да | нет |
| Зачем | сайт, поиск, фильтры, корзина | git, Obsidian, бэкап папки |

- Открытие `/n/42` читает строку из SQLite, не диск.
- После сохранения из интерфейса пишется зеркало `docs/<тип>/<основная-область>/<slug>.md`.
- Если файл не записался, элемент всё равно жив.
- Файл без элемента в библиотеке не виден, пока его не импортировали.
- При расхождении побеждает база: диск сам карточку не переписывает.

Картинки — та же схема: запись в `files` + байты в `data/media/<id заметки>/`. В markdown ссылка вида `![](/media/184)`, не base64.

Подробности схемы и потоков — в [DESIGN.md](./DESIGN.md).

## Типы и области

Справочники в таблице `taxons`, правятся на странице **Справочники** (`/settings`).

Стартовый набор типов: Промпт, Инструкция, Подборка, Заметка, Шпаргалка.  
Области: Графика, Видео, Тексты, Маркетинг, Аналитика, Агенты, Код, Инструменты, Учёба, Бизнес.

Можно добавить свои. Код (slug) идёт в путь файла; название — на экране.  
У записи **несколько областей** (чипы в редакторе). Фильтр «Графика» показывает все заметки, где графика есть среди областей. Первая выбранная область — основная для пути зеркала.

Удаление пункта, на котором висят записи, попросит **куда перенести**.

## Импорт архива

Папка `docs/` уже содержит разобранный архив (~580 markdown-файлов по типам и областям).

При **первом** запуске, если база пустая, сервер обходит `docs/**/*.md` и создаёт элементы. Вшитые `data:image/…` вытаскиваются в `files`.

Повторный импорт с диска (когда база уже есть) не затирает изменённые в интерфейсе карточки. Новый файл без записи в базе можно подтянуть через `POST /api/import` (или `GET /api/import`).

## Структура репозитория

```
app/                 страницы и API (Next.js App Router)
  page.tsx           библиотека
  n/[id]/            просмотр и /edit
  new/               создаёт черновик и редирект в редактор
  settings/          типы и области
  media/[id]/        отдача картинок по /media/<id>
  api/               notes, files, taxons, import
components/          Library, Editor, NoteView, Lightbox, …
lib/                 SQLite, импорт, таксономия, пути
docs/                зеркала заметок (можно править снаружи)
data/                notebook.db и media/ — не в git
DESIGN.md            проектные решения
```

## Полезные адреса

| Путь | Что |
|---|---|
| `/` | библиотека |
| `/?q=…&type=prompt&domain=image&sort=title&dir=asc` | поиск, фильтры, сортировка |
| `/n/42` | просмотр |
| `/n/42/edit` | правка |
| `/new` | новая запись |
| `/settings` | справочники |
| `/media/184` | файл картинки |
