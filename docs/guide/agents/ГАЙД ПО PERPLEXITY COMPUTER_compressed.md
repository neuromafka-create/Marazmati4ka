# Что такое Perplexity
# Computer

Perplexity Computer — это ИИ-агент нового поколения, который
объединяет поиск, анализ, код, документы, браузерные действия
и автоматизацию в одной системе.

Это не просто чат-бот, а цифровой исполнитель, который может
доводить задачу до результата.

# Что такое ИИ-агент простыми словами

Ключевая идея

В отличие от обычных ИИ-ассистентов, Computer не только отвечает
на вопросы, но и выполняет полноценную работу:

исследует тему

строит план

запускает параллельные подзадачи

создаёт файлы

взаимодействует с внешними сервисами

возвращает готовый результат

# Возможности:
# суб-агенты и интеграции

Суб-агенты

Perplexity Computer умеет разбивать большую задачу

на несколько параллельных рабочих потоков.

Что это значит на практике

несколько подзадач выполняются одновременно

у разных подзадач могут быть разные модели и инструменты

все промежуточные результаты собираются в общем рабочем
контексте

# Как начать работу

Выберите подходящий тариф

Max — вариант для пользователей, которым нужен расширенный доступ

Лучше формулировать не шаги, а конечный результат: не «зайди туда,

таблицу / документ / презентацию»

Подключите нужные сервисы

Gmail, Slack, Calendar, Notion и другие инструменты, с которыми агент

будет работать

Используйте память и историю работы

Computer может учитывать контекст прошлых диалогов и предыдущих

задач

Советы по эффективной работе

- описывайте конечный результат
- проверяйте план выполнения
- используйте параллельные сценарии для объёмных задач
