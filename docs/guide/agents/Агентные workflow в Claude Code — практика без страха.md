## 5 идей, которые стоит запомнить

Основная идея. Claude Code — это не инструмент для программистов. Это
платформа для создания персональных AI-агентов, которые через MCP-серверы
подключаются к любым внешним сервисам и автоматизируют реальные задачи
бизнеса. Общение с агентом остаётся в формате обычного чата — меняется только
масштаб того, что он делает за тебя.

Ключевые выводы:

1.​ AI-агент = нейросеть + внешние инструменты. Как только LLM получает
доступ к управлению файлами, сервисами и данными — она перестаёт быть
просто чатботом и становится агентом, способным действовать.​
2.​ Терминальная версия Claude Code мощнее десктопного приложения.
Файловый менеджер, MCP-подключения, подкапотные настройки — всё это
доступно только в терминале. Десктоп — это демо, терминал — боевой режим.​
3.​ MCP-сервер подключается за 2 клика. Скопировал команду из Smithery,
вставил в терминал — и Notion, Google Sheets или Gmail уже работают в паре с
твоим агентом.​
4.​ Агентные цепочки — это разделение труда. Один агент ищет, второй пишет,
третий ревьюит. Они работают параллельно, как слаженная команда — ты
только ставишь задачу.​
5.​ Промпт важнее кода. Главная компетенция в работе с Claude Code —
правильно описать задачу и контекст. Никакого программирования не
требуется.​

## ChatGuide: вопросы и ответы

1. Что такое Claude Code и почему он набирает такую популярность?

Кратко: Claude Code — это не просто чат с ИИ. Это среда, в которой ты строишь
агентов, управляющих твоими файлами, сервисами и задачами.

Claude Code — продукт от Anthropic, который устанавливается прямо внутри других
программ (например, VS Code) или запускается через терминал. В отличие от обычной
веб-версии Claude, здесь у тебя есть полноценный файловый менеджер, доступ к
настройкам «под капотом» и возможность подключать любые внешние сервисы через
MCP-серверы.

Популярность объясняется просто: Claude Code использует самые топовые языковые
модели Anthropic, при этом открывает такой уровень кастомизации, который раньше
был доступен только опытным разработчикам. Сегодня это инструмент номер один
среди профессиональных автоматизаторов и технических специалистов, работающих
с AI-агентами.

Для непрограммистов это тоже стало доступно — потому что всё общение с агентами
происходит в формате обычного чата. Ты пишешь задачу словами, агент её выполняет.
Никакого кода.

1. Зачем мне Claude Code, если я не программист и не разработчик?

Кратко: Потому что Claude Code — это не про код. Это про то, чтобы твой
AI-помощник мог делать реальные действия, а не просто отвечать на вопросы.

Представь разницу между калькулятором и бухгалтером. Калькулятор считает, когда ты
нажимаешь кнопки. Бухгалтер — сам открывает таблицы, вносит данные, формирует
отчёт и отправляет его нужному человеку. Claude Code превращает нейросеть из
калькулятора в бухгалтера.

Конкретные сценарии для не-разработчика: автоматический сбор информации с
YouTube по нужной теме и оформление в PDF-отчёт, публикация постов в Instagram по
расписанию, создание и обновление страниц в Notion, работа с Google-таблицами без
ручного ввода. Всё это настраивается один раз и потом работает само.

Ключевой навык, который нужен, — умение чётко описать задачу и контекст. Это ты
уже умеешь, просто раньше не применял к AI-агентам.

### принципиальная разница?

Кратко: Обычная нейросеть отвечает. AI-агент — действует.

Если работать с ChatGPT или обычным Claude в браузере, взаимодействие выглядит

AI-агент — та же самая языковая модель, которой дали доступ к внешним

сам заливает файл.

Образно: обычная нейросеть — это очень умный советник, который всё знает, но
ничего не делает руками. AI-агент — это тот же советник, которому дали компьютер,
телефон и доступ ко всем твоим системам.

1. Как установить Claude Code и какая версия нужна для полного
### функционала?

Кратко: Полный функционал — только в терминальной версии. Установка занимает
несколько минут.

Существует несколько вариантов Claude Code: веб-версия, десктопное приложение
для Mac и Windows, расширение внутри VS Code и терминальная версия. Для
серьёзной работы с агентами нужна именно терминальная — только там доступны
файловый менеджер, MCP-подключения и полная кастомизация.

Установка происходит через одну команду в терминале. После установки в
интерфейсе VS Code появляется статус-лайн Claude Code — это сигнал, что всё готово
к работе. Важно: потребуется аккаунт Anthropic и подписка, дающая доступ к Claude
Code (уточняй актуальные условия на сайте Anthropic).

Если слово «терминал» пугает — не переживай. Это просто текстовое окно, в которое
вставляется одна строчка. Ничего сложнее копипаста на старте не нужно.

1. В чём разница между расширением Claude Code в VS Code и
### терминальной версией?

Кратко: Расширение — удобный интерфейс, терминал — полная мощность.
Профессионалы работают с терминалом.

Расширение Claude Code внутри VS Code — это визуальная оболочка, которая делает
работу комфортнее для тех, кто уже пользуется VS Code как редактором. Оно хорошо
для написания и правки кода в связке с AI.

Терминальная версия — это Claude Code без ограничений. Именно она имеет полный
доступ к файловой системе, позволяет устанавливать и управлять MCP-серверами,
запускать агентные цепочки в параллельных окнах через Agent Teams, работать с
проектами и скиллами. Все топовые автоматизаторы используют именно её.

Если цель — создавать AI-агентов для автоматизации бизнес-задач, а не просто
писать код с подсказками — нужен терминал. Расширение — это вспомогательный
инструмент, терминал — основная рабочая среда.

1. Что такое MCP-серверы и почему они — сердце агентной
### системы?

Кратко: MCP-серверы — это «руки» агента. Без них агент может только думать. С
ними — действовать.

MCP расшифровывается как Model Context Protocol. По сути это стандартизированные
коннекторы, которые позволяют Claude Code подключаться к любому внешнему
сервису: Google-таблицам, Notion, Gmail, GitHub, Slack, Instagram, YouTube и сотням
других.

Представь агента как очень умного сотрудника, которого наняли, но не дали ни
компьютер, ни телефон, ни доступ ни к каким системам. Он умный, но бесполезен.
MCP-серверы — это его рабочий инструментарий. Подключил Google Sheets → агент
теперь умеет читать и писать в таблицы. Подключил Gmail → агент умеет отправлять
письма. Каждый MCP — это новая «способность».

Именно поэтому MCP — сердце всей системы. Чем больше MCP подключено, тем
шире зона действия агента, тем большую часть работы он берёт на себя.

1. Как подключить Notion, Google Sheets или Gmail к Claude Code
### через MCP?

Кратко: Два клика и одна команда в терминале. Буквально.

Алгоритм одинаков для любого сервиса:

1.​ Заходишь в Smithery (библиотека MCP-серверов).
2.​ Находишь нужный сервис (Notion, Google Sheets, Gmail — всё есть).
3.​ Переходишь во вкладку Humans, выбираешь Claude Code.
4.​ Копируешь одну команду.
5.​ Вставляешь её в терминал внутри Claude Code.

После этого открывается браузер с окном авторизации — логинишься в своём аккаунте
(например, в Notion или Google). Готово — MCP подключён, агент теперь работает с
этим сервисом.

1. Что такое скиллы в Claude Code и как их правильно
### использовать?

Кратко: Скилл — это готовая инструкция для агента, которая объясняет ему, как
выполнять конкретный тип задач. Как установить скилл повара на робота.

Если MCP-серверы дают агенту доступ к инструментам, то скиллы объясняют ему, как
ими пользоваться в конкретном контексте. Скилл — это набор инструкций и правил под
определённую задачу: как делать дизайн для сайта, как работать с PDF, как проводить
discovery-интервью, как создавать презентации в PowerPoint.

Когда устанавливаешь скилл, агент начинает вести себя как специалист в этой
области, а не как универсал. Это как разница между «помогите с документом» и «я
нанял технического редактора с чёткими стандартами работы».

Скиллы устанавливаются из Smithery за несколько кликов. После установки просто
упоминаешь нужный скилл в задаче — агент сам его применяет.

1. Что такое Smithery и как найти нужный скилл среди 128 000
### вариантов?

Кратко: Smithery — это App Store для Claude Code. 128 000 скиллов и MCP-серверов,
поиск работает на русском языке.

Smithery — это внешний каталог-библиотека, где собраны тысячи готовых
MCP-серверов и скиллов для Claude Code. Заходишь, вводишь в поиск то, что тебе
нужно — на русском или английском — и находишь готовое решение.

Примеры из практики: нужен скилл для работы с дизайном — ищешь «frontend design»,
устанавливаешь. Нужен скилл для discovery-интервью — вводишь «discovery» и
находишь готовую инструкцию. Нужен MCP для Notion — ищешь «Notion», копируешь
команду. Нужно подключить Instagram — есть и такое.

Важный нюанс: в Smithery можно найти скиллы, которые помогают создавать
собственные скиллы. То есть система позволяет не только потреблять готовое, но и
кастомизировать под свои задачи. Это открывает возможность строить уникальные
агентные системы под конкретный бизнес.

1. Как создать агентную цепочку, где несколько агентов работают
### как команда?

Кратко: Каждый агент получает свою роль и зону ответственности. Они передают
результат друг другу, как конвейер.

Агентная цепочка — это несколько AI-агентов внутри одного проекта, каждый из
которых заточен под конкретную функцию. Классический пример из практики:

●​ Агент-скрепер — собирает данные (например, с YouTube по заданной теме)
●​ Агент-аналитик — обрабатывает собранное, выделяет ключевое
●​ Агент-репортер — формирует структурированный отчёт
●​ Агент-брифинг — готовит финальный документ в нужном формате (PDF,
Google Sheets)

Каждый агент настраивается отдельно с чётким описанием его роли и инструментов.
Ты создаёшь такую систему один раз, а дальше запускаешь одной командой в чате —
агенты сами распределяют работу и передают результаты друг другу.

Строить цепочку нужно начинать с самой простой — два агента, чёткая задача.
Постепенно добавлять звенья по мере понимания, как каждый из них работает.

1. Можно ли настроить автопостинг в Instagram или YouTube через
### Claude Code?

Кратко: Да. Агент может сам публиковать посты, заливать видео и создавать контент в
сервисах — без твоего участия.

Через MCP-серверы Claude Code получает доступ к внешним платформам, включая
Instagram и YouTube. После подключения соответствующего MCP агент может:
публиковать посты в Instagram по расписанию или по триггеру, заливать ролики на
YouTube с описанием и тегами, создавать и обновлять страницы в Notion, вносить
данные в Google-таблицы.

Важная оговорка: с подобными автоматизациями нужно работать аккуратно и всегда
проверять результат перед финальным запуском в боевом режиме. Слепое доверие
без контроля — это риск. Но как инструмент для ускорения рутинных задач — это
работает и экономит десятки часов в месяц.

Для начала рекомендуется настроить такой сценарий в тестовом режиме: агент
готовит контент и сохраняет его для твоей проверки, а публикует только после
подтверждения.

1. Что такое Agent Teams и как агенты работают параллельно в
### разных окнах?

Кратко: Agent Teams — режим, в котором Claude Code запускает несколько агентов
одновременно, каждый в своём окне. Как настоящая команда, работающая
параллельно.

В обычном режиме агенты выполняют задачи последовательно. Agent Teams — это
продвинутая конфигурация, при которой Claude Code открывает несколько
параллельных окон-терминалов, в каждом из которых работает отдельный агент над
своей задачей одновременно.

Результат: то, что последовательно заняло бы час, при параллельной работе четырёх
агентов занимает 15 минут. Один парсит, второй анализирует данные из первого,
третий пишет отчёт, четвёртый уже готовит финальный документ — и всё это
одновременно.

Настройка Agent Teams — отдельная тема, требующая чуть больше времени на
изучение. Хорошая отправная точка — YouTube-канал Никиты Велса, где есть
отдельное видео с подробным разбором именно этой функции.

1. Как правильно описывать задачи и контекст для AI-агента?

Кратко: Чем точнее описан контекст и ожидаемый результат — тем лучше работает
агент. Это главный навык в работе с Claude Code.

Агент не читает мысли. Он работает ровно с той информацией, которую ты ему дал.
Поэтому структура хорошего промпта для агента выглядит так:

1.​ Контекст — кто ты, что за проект, какая цель
2.​ Задача — что конкретно нужно сделать (глагол + объект + детали)
3.​ Формат результата — что должно получиться на выходе (PDF, таблица, пост,
список)
4.​ Ограничения — чего делать не нужно или что важно учесть

Пример плохого запроса: «Сделай мне что-нибудь про AI-агентов». Пример хорошего:
«Запусти AgentTeams на парсинг YouTube по теме AI-агентов, собери топ-20 видео за
последние 3 месяца, сформируй PDF-отчёт с названиями, ссылками и кратким
описанием каждого».

Хороший промпт — это 80% успеха. Claude Code делает остальное.
