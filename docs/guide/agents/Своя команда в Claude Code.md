🛠 Своя /команда в Claude Code: превращаем затёртый промт в один слэш

Если ты раз за разом вставляешь в Claude Code одну и ту же простыню («проверь код на ошибки и стиль…», «сделай коммит по нашим правилам…») — это сигнал. Такой промт пора превратить в свою команду. Один раз настроила → дальше просто /команда.

Делается за 2 минуты, без кода 👇

Шаг 1. Найди свой «затёртый» промт

Не выдумывай команды наперёд. Возьми текст, который реально печатаешь чаще всего за последнюю неделю. Именно его и автоматизируем.

Шаг 2. Создай файл

Команда — это просто текстовый .md-файл. Имя файла = имя команды.

Два места:
— .claude/commands/ в проекте → команда живёт в этом проекте (и шарится с командой через git)
— ~/.claude/commands/ в домашней папке → работает во ВСЕХ твоих проектах

Например, создаём ~/.claude/commands/review.md и пишем внутри:

Проверь изменения на баги, дыры в безопасности и стиль. Код не правь — выдай только список замечаний.

Всё. Теперь в любой сессии набираешь /review — и Claude делает ровно это.

Шаг 3. Добавь подстановку (по желанию)

Хочешь передавать команде ввод? Вставь в текст $ARGUMENTS — туда подставится всё, что напишешь после команды.

Файл fix-issue.md:
Разберись и почини задачу №$ARGUMENTS. Сначала посмотри детали, потом предложи фикс.

Вызов: /fix-issue 123 → подставится 123.
Нужны отдельные аргументы — бери $1, $2 («…приоритет $2, исполнитель $3»).

Шаг 4. Поставь рамки (для безопасности)

Сверху файла можно добавить блок настроек между ---. Самое полезное — allowed-tools: разрешить команде только то, что нужно, и ничего лишнего.

---
description: Создать git-коммит по нашим правилам
allowed-tools: Bash(git status:*), Bash(git commit:*)
---
Сделай коммит. Сначала глянь статус, потом сформулируй сообщение.

Конструкция ! перед командой даёт живой вывод: Claude сам запустит, например, git status и увидит результат ещё до старта. А description будет видно в меню, когда жмёшь /.

Важный момент

Раньше «команды» и «скиллы» жили раздельно — теперь это одна система. Файлы в .claude/commands/ работают как и работали, но если захочешь больше (свои скрипты, автозапуск по контексту) — Anthropic советует складывать в .claude/skills/. Для старта хватит обычной команды.

Проверь, что подхватилось: набери / — твоя команда должна быть в списке.
