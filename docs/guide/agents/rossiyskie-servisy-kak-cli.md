# Что такое CLI и зачем он агенту

CLI — это маленькая программа, которую запускают одной командой. Ты

пишешь команду — она делает одну задачу и выдаёт результат. Например:

«покажи мои заказы на Ozon» → список заказов.

Почему это удобно для агента: команда всегда работает одинаково, её легко проверить, и агент может

позвать её сам, когда она нужна. По сути мы даём агенту кнопку «сделать вот это с сервисом» — и он ей

пользуется.

Прежде чем собирать инструмент, посмотри, как вообще устроен доступ к сервису. Обычно это одна из трёх

# Почему CLI, а не MCP

Ты мог слышать про MCP — это другой способ подключить сервис к

ассистенту. Он тоже рабочий, но для наших задач CLI удобнее. Разница

простая.

| ЧТО ВАЖНО | MCP | CLI (НАШ ВЫБОР) |
| --- | --- | --- |
| Занимает ли «память» Да — «висит» включённым всегда, даже Нет — молчит, пока его не позвали агента когда не нужен |  |  |
| Много сервисов сразу Чем больше подключено, тем агенту Спокойно: инструментов может быть тяжелее много |  |  |

# Что поставить в Claude Code

Нужны два помощника. Первый собирает инструмент, второй учит агента им

пользоваться. Ставить их тоже поможет сам Claude Code — просто попроси.

1. Генератор инструментов /cli-anything

Это плагин, который по документации сервиса собирает готовый CLI. Попроси Claude Code установить его:

✍️ СКОПИРУЙ В CLAUDE CODE

Установи мне команду /cli-anything из репозитория github.com/HKUDS/CLI-Anything и коротко объясни, как

её запускать.

1. Помощник /skill-creator

Он делает маленькую «инструкцию» (Skill), по которой агент сам понимает, когда звать твой инструмент.

Обычно уже встроен в Claude Code — проверь так:

✍️ СКОПИРУЙ В CLAUDE CODE

У меня есть команда /skill-creator? Если нет — подскажи, как её добавить.

# Собираем инструмент по шагам

Дальше всё в Claude Code. На каждом шаге — что сделать и какую фразу

написать. Пример на Ozon, но так же для любого сервиса с API.

Шаг 1. Дай Claude Code материалы о сервисе

Найди страницу документации сервиса «для разработчиков» (API). Скопируй ссылку. Дальше:

✍️ СКОПИРУЙ В CLAUDE CODE

Вот документация сервиса: [вставь ссылку]. Собери мне инструмент (CLI) через /cli-anything: команды под

мои задачи — заказы, остатки, цены. Ответы выдавай в удобном для программы виде (JSON). Ключ доступа

бери из настроек, не пиши его в код.

Шаг 2. Дождись, пока Claude Code соберёт

Claude Code сам разберёт документацию, напишет инструмент и покажет, какие команды получились. Тебе не

нужно читать код — достаточно понять, что инструмент умеет. Если чего-то не хватает — так и скажи:

«добавь команду, которая обновляет цену товара».

# Когда у сервиса нет API

Даже если у сервиса нет «официального» способа подключения, выход есть.

Сайт ведь как-то показывает тебе данные в личном кабинете — значит, он

сам обменивается ими со своим сервером. Мы дадим Claude Code

«подсмотреть» этот обмен.

Что сделать руками (это просто)

Открой личный кабинет сервиса в браузере Chrome.

Нажми F12 — откроется панель разработчика. Перейди на вкладку Network
(Сеть).

Пощёлкай по нужному разделу сайта (например, «Мои заказы») — в панели

появятся строки запросов.

Нажми правой кнопкой на нужную строку → Copy → Copy as cURL. Это скопирует

«как сайт запросил данные».

## Page 8

Теперь отдай это Claude Code — он сам поймёт структуру и соберёт инструмент:

✍️ СКОПИРУЙ В CLAUDE CODE

У сервиса [название] нет открытого API. Я скопировал из браузера, как сайт запрашивает данные

(прикладываю). Разберись, как он общается со своим сервером, и собери инструмент, который делает то

же самое — например, получает список моих заказов.

⚠️
Пара честных предупреждений. Автоматизируй только свой кабинет и свои данные. Такой инструмент может

сломаться, если сервис поменяет сайт — тогда просто попроси Claude Code починить. А вот госуслуги и

банки с электронной подписью — это отдельная сложная история, для первого раза выбери сервис попроще.

# Российские особенности

У наших сервисов бывают мелкие странности в данных. Пугаться не нужно:

заметил что-то не то — просто скажи об этом Claude Code, и он поправит

инструмент.

## Page 9

Кракозябры вместо русских букв — старая кодировка. Скажи: «в ответах вместо

русских букв непонятные символы, поправь кодировку».

Даты и суммы в другом виде (10.07.2026 вместо привычного, суммы с запятой) —

«приведи даты и суммы к нормальному виду».

Номера ИНН/КПП с нулями впереди — «храни такие номера как текст, чтобы нули

не пропадали».

Сервис ругается на «слишком много запросов» — «добавь паузы и повтор, если

сервис просит подождать».

🛠️
Общий приём на все случаи: показал Claude Code, что пошло не так → он объяснил и починил. Тебе не нужно

знать, как это устроено внутри — достаточно описать проблему словами.

# Чтобы агент сам звал инструмент

Инструмент готов, но агент пока не знает, когда им пользоваться. Дадим ему

короткую инструкцию — Skill. Тогда на фразу «покажи мои заказы на озоне»

агент сам вызовет нужную команду.

## Page 10

✍️ СКОПИРУЙ В CLAUDE CODE

Сделай через /skill-creator короткую инструкцию (Skill) к моему инструменту: когда его звать (по фразам

вроде «мои заказы на озоне», «обнови остатки», «выгрузи товары»), пара примеров команд и на что

обратить внимание.

Всё. Теперь у тебя есть рабочий инструмент и агент, который сам знает, когда его использовать. Следующий

сервис делается точно так же — повтори те же шаги.

🔁
Совет. Начни с одного сервиса, где есть API (Ozon, Telegram, банк) — так проще всего почувствовать, как это

работает. А дальше каждый следующий инструмент будет даваться легче: шаги те же, а Claude Code делает

основную работу.
