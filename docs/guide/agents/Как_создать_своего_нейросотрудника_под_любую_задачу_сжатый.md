Напишите любое сообщение

## Page 3

# 03 СОЗДАЙТЕ
# НОВОГО АГЕНТА

Нажмите:

👉 Создать агента / Create agent

Укажите:

Название:
(например: “Ассистент”, “Аналитик”,
“Куратор”)

Описание:
что он делает, какой функционал

Агент создан

# 04 СРАЗУ
# ПОДКЛЮЧИТЕ
# TELEGRAM

Перейдите в раздел:

👉 Integrations (Интеграции)

Выберите Telegram

Вставьте токен бота (из шага 1)

Нажмите Сохранить

ваш агент связан с Telegram

## Page 4

# 05 ОПРЕДЕЛИТЕ
# РОЛЬ НЕЙРО-
# СОТРУДНИКА

Перед настройкой зафиксируйте:

Заполните:

Кто он:
(например: аналитик, ассистент, куратор)

Что делает:
(конкретная задача)

Чего НЕ делает:
(границы)

Цель:
(результат работы)

Стиль:
(как отвечает)

Это основа агента

# 06 НАСТРОЙТЕ
# ИНСТРУКЦИЮ

Мозг

Найдите поле: Instruction / Prompt

## Page 5

Вставьте и адаптируйте

Вы — [роль].

Ваша задача — [что делает агент].

Вы работаете в контексте:
[опишите нишу или проект]

Правила:
- отвечаете только по теме
- не придумываете информацию
- если не знаете — говорите об этом
- даёте понятные ответы

Стиль:
- [коротко / структурно / дружелюбно /
экспертно]

Цель:
- [результат для пользователя]

Это логика поведения агента. Чем
подробнее вы распишите, тем качественнее
он будет работать.

# 07 ДОБАВЬТЕ
# БАЗУ ЗНАНИЙ

Перейдите в:

Knowledge / База знаний

## Page 6

Добавьте:

описание продукта или темы

инструкции

правила

FAQ

примеры

Важно

агент отвечает на основе этих данных

чем точнее база — тем лучше результат

# 08 НАСТРОЙТЕ
# ПОВЕДЕНИЕ

Перейдите в: Response / Поведение

Задайте:

язык: авто
длина: короткая / средняя
стиль: нужный вам

Добавьте правила:

- не писать длинные тексты
- не уходить от темы
- отвечать по делу
