# **0. Что такое gstack и почему он меняет всё**

gstack — это открытый инструментарий от Гарри Тана, президента Y Combinator (инкубатор Coinbase, Airbnb, Stripe). За 60 дней с его помощью написано более 600 000 строк production-кода — 10 000–20 000 строк в день — одним человеком, совмещающим это с управлением организацией.

| 📊  Ключевые цифры gstack  54 200+ звёзд на GitHub (один из самых популярных AI-инструментов 2026 года) 7 000+ форков — разработчики по всему миру адаптируют под себя 28 специализированных агентов-«специалистов» в одной системе Автор: Гарри Тан, President & CEO Y Combinator |
| --- |

## **Главная идея gstack: «Спринт как процесс»**

gstack превращает ИИ не в «умный чат», а в настоящую команду разработчиков, работающих по чёткому процессу:

| THINK → PLAN → BUILD → REVIEW → TEST → SECURITY → SHIP → RETRO    Каждый этап — отдельный специалист:   /office-hours   = YC-наставник (переформулирует задачу)   /plan-ceo-review = CEO (стратегия продукта)   /plan-eng-review = Тимлид (архитектура, диаграммы)   /review          = Staff Engineer (баги в продакшне)   /qa              = QA Lead (реальный браузер)   /cso             = Директор по безопасности (OWASP+STRIDE)   /ship            = Release Engineer (тесты + PR)   /retro           = Тимлид (еженедельный разбор полётов) |
| --- |

## **Что мы берём из gstack для офлайн-системы**

| Концепция gstack | Как адаптируем для офлайна |
| --- | --- |
| Спринт-процесс Think→Plan→Build→…→Retro | Берём полностью — это структура работы, не зависящая от интернета |
| Специалисты: CEO, Тимлид, QA, CSO, Release | Заменяем Claude API → локальные модели Ollama |
| SOUL-файлы (личность агента) | Markdown-файлы в AI_Brain/agents/ — работает офлайн |
| CAREFUL + FREEZE (защита от ошибок) | Правила в AI_Brain/rules/ — работает офлайн |
| MASTER_TODO + DAILY_REPORT | Берём без изменений из «Клешни» |
| RETRO — еженедельный отчёт | Добавляем как отдельного агента |
| /investigate — системная отладка | Добавляем как отдельного агента |
| /cso — аудит безопасности | Добавляем как отдельного агента |
| Claude Code + браузер Playwright | НЕ применимо офлайн — пропускаем |
| Conductor (параллельные спринты) | НЕ применимо офлайн — пропускаем |

## **5.1 Скрипт-оркестратор**

Создай файл C:\AI_Brain\orchestrator.py — это «диспетчер», который запускает агентов по расписанию:

| import schedule, time, subprocess, os from datetime import datetime  BRAIN = 'C:/AI_Brain' OLLAMA = 'ollama run'  def planner_tick():     """Каждый час — Планировщик проверяет задачи"""     inbox = os.path.join(BRAIN, 'inbox')     tasks = [f for f in os.listdir(inbox) if f.endswith('.md')]     if tasks:         print(f'[{datetime.now()}] Планировщик: найдено задач: {len(tasks)}')         # Здесь вызов Планировщика через Ollama API         # subprocess.run([OLLAMA, 'qwen3:14b', ...])  def daily_report():     """Каждый вечер в 21:00 — дневной отчёт"""     print(f'[{datetime.now()}] Создаю DAILY_REPORT...')  def weekly_retro():     """Каждое воскресенье в 23:00 — недельный ретро"""     print(f'[{datetime.now()}] Запускаю WEEKLY_RETRO...')  # Расписание schedule.every().hour.do(planner_tick) schedule.every().day.at('21:00').do(daily_report) schedule.every().sunday.at('23:00').do(weekly_retro)  print('Нейро-Мастерская запущена. # **8. Решение типичных проблем**

| Проблема | Возможная причина | Решение |
| --- | --- | --- |
| Модель не отвечает / завис | Ollama не запущен | cmd → ollama serve → перезагрузи Open WebUI |
| Модель отвечает очень медленно | Модель в ОЗУ вместо VRAM | Кодер должен быть в VRAM: ollama run qwen2.5-coder:7b |
| Open WebUI не открывается | Порт занят или не запущен | cmd → open-webui serve → подожди 60 сек |
| ollama list пустой (нет моделей) | Папка .ollama не скопирована | Скопируй .ollama из флешки в C:\Users\ИМЯ\ |
| pip install не работает офлайн | Пакеты не скачаны на флешку | Выполни команду pip download с Раздела 2.4 |
| Агент лезет за пределы AI_Brain | SOUL-файл не настроен | Добавь FREEZE-правило в SOUL-файл агента |
| Компьютер перегревается | Работа 24/7 без охлаждения | Проверь вентиляторы, установи HWiNFO64 для мониторинга |
