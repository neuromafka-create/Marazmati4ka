# Как подключить файлы к Hermes

Туториал: научи своего AI-агента отвечать по твоим личным файлам (PDF,
заметки, конспекты, расшифровки) через синхронизированную папку.

## Что получим в итоге

- Папка на Маке ~/Hermes-Knowledge/ синхронизируется с папкой на VPS
/root/.hermes/knowledge/
- Кидаешь файл в папку — через 5-10 секунд он у Hermes
- Спрашиваешь в Telegram «что у меня в библиотеке про X» — Hermes находит и
отвечает
- Никаких облаков-посредников: прямой P2P-канал между Маком и VPS

Время на всё: 15-20 минут. Условие: Hermes уже стоит на твоём VPS (это было в прошлом ролике).

## Часть 1. Установка Syncthing на VPS

Заходим на VPS по SSH:

ssh root@твой-ip

Ставим Syncthing из системного репозитория:

apt update && apt install -y syncthing

Включаем автозапуск через systemd:

loginctl enable-linger root
systemctl --user enable syncthing
systemctl --user start syncthing

Проверяем что работает:

systemctl --user status syncthing | head -5

Должно быть active (running).

Узнаём Device ID нашего VPS

Это уникальный отпечаток VPS. Понадобится Маку чтобы его «увидеть».

syncthing --device-id

Получишь длинную строку из букв через дефисы. Скопируй её — пригодится через минуту.

Открываем доступ к веб-UI Syncthing

Веб-UI Syncthing торчит только локально на VPS. Чтобы зайти в него с Мака, прокидываем
SSH-туннель. В новом окне терминала на Маке:

ssh -L 8385:127.0.0.1:8384 root@твой-ip

## Page 2

Окно держим открытым. В браузере на Маке открываем:

http://127.0.0.1:8385

Видим веб-интерфейс Syncthing на VPS. На первом запуске спросит логин-пароль
(поставь любые, нужны только тебе).

## Page 3

## Часть 2. Установка Syncthing на Мак

Идём на https://syncthing.net/downloads, раздел macOS, скачиваем .dmg-файл.

Открываем dmg, перетаскиваем в Applications, запускаем. В меню-баре появится значок
Syncthing.

Веб-UI Mac-версии открывается автоматически на:

http://127.0.0.1:8384

Узнаём Device ID Мака

В веб-UI Мака: правый верхний угол → Actions → Show ID. Скопируй строку.

## Часть 3. Связать VPS и Мак

На Маке: добавить VPS как Remote Device

В веб-UI Mac (http://127.0.0.1:8384):

1. Внизу справа кнопка Add Remote Device
1. В поле Device ID — вставляешь Device ID VPS (из Части 1)
1. Name: VPS Hermes (любое имя)
1. Save

На VPS: принять подключение

Через минуту в веб-UI VPS появится плашка «New Device, Add». Нажимаешь:

1. Name: MacBook (или как у тебя)
1. Save

Через 10-30 секунд в разделе Remote Devices статус устройства должен стать зелёным
«Connected».

## Page 4

## Часть 4. Создать общую папку

На Маке: создать папку и расшарить

Создаём папку в домашней директории:

mkdir -p ~/Hermes-Knowledge

В веб-UI Mac:

1. Слева кнопка Add Folder
1. Folder Label: Hermes Knowledge
1. Folder ID: knowledge (важно, не меняй)
1. Folder Path: ~/Hermes-Knowledge
1. Вкладка Sharing → отметь галочкой VPS Hermes
1. Save

На VPS: принять share

Через 30 секунд в веб-UI VPS появится плашка с предложением расшарить папку.
Нажимаешь Add:

- Folder Path: /root/.hermes/knowledge
- Save

Через минуту в разделе Folders статус должен быть Up to Date зелёным.

## Часть 5. Подключить папку к Hermes

Hermes уже умеет работать с файлами в /root/.hermes/knowledge/: это его дефолтное
место для пользовательских материалов.

Чтобы Hermes понимал что «мастерская», «мои файлы», «моя библиотека» — это про эту
папку, обновим его системный промпт:

nano /root/.hermes/SOUL.md

В конец файла добавляем абзац:

## Моя мастерская знаний

Когда я говорю «мастерская», «моя база», «мои конспекты»,
«то что я загружал» — я имею в виду папку
/root/.hermes/knowledge/.

Когда я спрашиваю «что у меня в мастерской про X»:
1. ls /root/.hermes/knowledge/
1. grep -ri "X" /root/.hermes/knowledge/
1. При нужде открой конкретный файл через cat.

Сохраняем (Ctrl+O, Enter, Ctrl+X). Перезапускаем Hermes:

systemctl --user restart hermes-gateway

## Page 6

## Часть 6. Демо — кидаем файл и спрашиваем

1. На Маке скачай или перенеси PDF в ~/Hermes-Knowledge/
1. Подожди 10-20 секунд
1. Открой Telegram, бот Hermes
1. Напиши: «что у меня в мастерской про [тема]»
1. Hermes найдёт файл, откроет, ответит по содержимому

## Что важно знать

Папка двусторонняя. Если удалишь файл на Маке — он удалится и на VPS. Если Hermes
сохранит что-то — это появится на Маке. Можешь попросить «сохрани мне эту статью в
мастерскую», и файл придёт прямо к тебе.

Скорость. Маленькие файлы (PDF до 10 МБ) синкаются за 5-10 секунд. Большие архивы —
за минуты.

Безопасность. Syncthing работает по зашифрованному протоколу прямо между
устройствами. Никакого облака-посредника.

Работает в фоне. Ничего не надо запускать руками. Сервис висит и сам синкает
изменения.

## Если что-то сломалось

| Проблема | Решение |
| --- | --- |
| Веб-UI VPS не открывается | Проверь что SSH-туннель из Части 1 запущен. lsof -i :8385 на Маке. |
| Устройства не видят друг друга | Подожди 2-3 минуты, NAT-обход требует времени. Проверь что порт 22000 открыт на VPS. |
| Папка не синкается | Веб-UI → Folders → клик на папке. Посмотри статус ошибок внизу. |
| Hermes не находит файлы | На VPS: ls /root/.hermes/knowledge/. Если пусто — синк не дошёл, ждём. |

## Что дальше: семантический поиск

Сейчас Hermes ищет по словам через grep. Это работает на 50-100 файлов. Для большой
библиотеки нужен семантический поиск через эмбеддинги и pgvector. Это уже другая
история: Supabase, индексатор, отдельный скилл. Расскажу в следующем ролике.

Для большинства случаев простого grep хватает с головой. Подключай свои файлы и
пробуй.
