## Page 3

Итак, 10 авторских усилителей промтов.

Если поделитесь с ближним кругом, Вам
точно скажут спасибо.

1
«Используй принцип “красной нити”»

Для нахождения главной темы или идеи, которая
связывает все аспекты проекта.

Пример: «Используй принцип “красной нити”,
чтобы выявить основную идею маркетинговой
кампании, объединяющую все сообщения».

2
«Применяй стратегию “золотой точки”»

Для нахождения идеального момента для принятия решения
или действий, когда эффект будет наибольшим.

Пример: «Применяй стратегию “золотой точки”,
чтобы определить момент, когда запуск продукта
принесёт наибольший отклик».

## Page 4

3
«Используй принцип “отказа от лишнего”»

Для устранения ненужных действий, которые не влияют
на конечный результат.

Пример: «Используй принцип “отказа от лишнего”,
чтобы убрать ненужные задачи в подготовке к ЕГЭ
и сосредоточиться на действительно важных».

4
«Применяй метод “точечного удара”»

Для концентрации на одном решении,
которое решает сразу несколько проблем.

Пример: «Применяй метод “точечного удара”, чтобы одной
стратегией охватить несколько рынков».

5
«Применяй правило “золотого действия”»

Для выявления одного ключевого действия,
которое может улучшить общие результаты.

Пример: «Применяй правило “золотого действия”,
чтобы определить один шаг, который радикально
повысит эффективность продаж».

## Page 5

6
«Используй принцип пирамиды»

Для выявления фундаментальных шагов, которые поддерживают
все остальные действия.

Пример: «Используй принцип пирамиды, чтобы
сосредоточиться на ключевых задачах, которые
обеспечивают основу успеха компании».

7
«Применяй принцип “золотой середины”»

Для нахождения баланса между двумя противоположными
подходами, который даст наилучший результат.

Пример: «Применяй принцип “золотой середины”, чтобы найти
оптимальное соотношение затрат и качества в проекте».

8
«Используй принцип домино»

Для определения одного ключевого шага, который приведёт
к каскаду успешных результатов.

Пример: «Используй принцип домино, чтобы выявить
действие, которое инициирует цепную реакцию
положительных изменений в эффективности HR-отдела».

## Page 6

9
«Используй принцип ключевого элемента»

Для нахождения одного элемента, который является
центральным для всего проекта.

Пример: «Используй принцип ключевого элемента,
чтобы выделить главную особенность продукта,
которая увеличит продажи».

10
«Используй метод “основного фокуса”»

Для концентрации только на самых важных задачах
и возможности игнорировать менее значимые.

Пример: «Используй метод “основного фокуса”, чтобы
выделить 3 основные цели на ближайший квартал».
