 КАК СОЗДАТЬ ТРЕНДОВОЕ ВИДЕО В НЕЙРОСЕТЯХ

1.  Получите готовый сценарий: Откройте ChatGPT и скопируйте этот промпт БЕЗ ИЗМЕНЕНИЙ:
Напиши сценарий мультфильма в стиле Тачки, где Главные герои оказываются в Москве. Сделай персонажей активными участниками — пусть они адаптируются, взаимодействуют с местными жителями, попадают в абсурдные, но веселые ситуации. Формат — горизонтальный стилистика мультфильма, не реализм. Сценарий должен быть забавным, визуально насыщенным, без реплик, только описание сцен, 5 кадров и без сложных действий

2. В том же диалоге добавьте промпт и ChatGPT сам обучится писать вам промпты (это как личный помощник): 
Проанализируй официальную документацию VEO-3 и создай детальное руководство по написанию промптов для анимационных видео с русской озвучкой. Укажи:
- Обязательные технические параметры
- Специфику промптов для мультипликации
- Как правильно описывать движения персонажей
- Примеры успешных формулировок для анимации
- Настройки звука и озвучки на русском языке

3.Создайте промпты для каждого кадра. Теперь попроси ChatGPT:
На основе изученной документации VEO-3 создай максимально детальный промпт для первого кадра моего сценария. Включи:
- Точное описание анимационного стиля
- Движения персонажей и камеры  
- Настройки звука и музыки
- Технические параметры для качественного результата
- Специфику мультипликации (не фотореализм)

Сделай промпт готовым к копированию в VEO-3.

4.
Теперь можете создавать видео
1. Откройте syntxaibot (https://t.me/syntxaibot?start=aff_244030591)
2. Выберите раздел Видео Будущего -> VEO -> Настройки модели (VEO-3 Fast)
3. Вставьте промпты из ШАГА - 3, по одному. 

Чем больше роликов генерируете, тем больше крутых кадров будет на выбор.

Дальше выберите лучшие дубли и соедините их в CapCut. Добавь переходы, музыку и готов трендовый мультик!

Вот так в нейросетях можно получить полноценный анимационный ролик с сюжетом, персонажами и профессиональной картинкой. Качество, как у студийного мультфильма.
