## Page 4

Это описание видео, но вряд ли оно подходит для
промпта: для нейросети он слишком перегружен
лишними деталями. Такие описания могут запутать AI,
и результат окажется далеким от ожидаемого.

Для достижения нужного результата
скорректируем запрос, сделав его лаконичнее:

«Магический кот в фиолетовой мантии и шляпе стоит
на скале под ночным звёздным небом. В лапах посох, из
которого летят разноцветные искры. Вокруг него парят
магические кристаллы. Атмосфера наполнена
волшебством»

Это описание уже больше похоже
на качественный промпт, который нейросети
смогут правильно интерпретировать.
Для уточнения добавим ещё один запрос:

«Добавь, пожалуйста, стиль»

ChatGPT в ответ предлагает:

Стиль фэнтези с богатой детализацией, мягкими
световыми эффектами и сказочной атмосферой

Теперь у нас есть полноценный промпт,
который нейросети могут успешно
обработать. Его можно использовать
для генерации изображения, которое
впоследствии оживляется с помощью
других инструментов AI.
