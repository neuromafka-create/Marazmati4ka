### Шаг 1: Подготовка — ​
### определите параметры

Перед открытием Lovable определите базовые параметры. ​
Это сэкономит время дальше

Что делать:

●​ Запишите 3-5 тем, на которые вы выступаете

●​ Определите типичную аудиторию (новички, коллеги, клиенты)

●​ Выберите длительность (10, 20, 45, 60 минут)

●​ Решите формат: питч, воркшоп, лекция или доклад

●​ Параметр Пример

●​ Тема​ Контент-маркетинг для малого бизнеса

●​ Аудитория Предприниматели без маркетолога

●​ Длительность 30 минут

●​ Формат Доклад на конференции

Совет: Чем точнее аудитория, тем лучше результат. «Предприниматели» —
размыто. «Владельцы кофеен, которые сами ведут соцсети» — точно

### Шаг 2: Создание приложения в Lovable

Откройте lovable.dev, создайте проект и вставьте промпт:

Создай веб-приложение «Помощник для презентаций» на React.

1. Форма ввода:
- Тема презентации (текст, обязательное)
- Целевая аудитория (текст, обязательное)

1. Результат — карточки слайдов: номер, заголовок, 3–5 тезисов, ​
заметки спикера, примерное время на слайд
1. Дизайн: светлая тема, Tailwind CSS, фиолетовый и белый.

Пока используй заглушки — пример структуры из 8 слайдов

## Page 5

### Шаг 3: Подключение AI

Заменим заглушки на реальную генерацию через Google Gemini

Промпт для Lovable:

Подключи Google Gemini API для генерации структуры презентации.

1. Поле для API-ключа в настройках (иконка шестеренки). ​
Ключ в local Storage
1. При нажатии «Создать структуру» отправь запрос в Gemini:

«Ты — эксперт по публичным выступлениям.

Создай структуру презентации:

Тема: {topic}, Аудитория: {audience}, Длительность: {duration}

Формат: {format}, Ключевые тезисы: {keyPoints}

Верни JSON-массив слайдов:

- slideNumber, title (краткий, цепляющий)
- bulletPoints (3-5 тезисов), speaker Notes (2-3 предложения)
- estimated Minutes

1 слайд на 2-3 минуты. Первый — титульный. Последний — итоги»

1. Обработай ошибки. Покажи результат в карточках

Копировать

Где взять API-ключ

Откройте Google AI Studio, нажмите «Get API key». ​
Бесплатного лимита хватает для десятков генераций в день

Ожидаемый результат: Через 10-15 секунд после отправки — ​
слайды с реальным содержанием по вашей теме

Промпт для Lovable:

Добавь секцию «Выбери шаблон» с карточками над формой:

- «Питч для инвестора» — проблема, решение, рынок, бизнес-модель,​
команда, финансы. Стиль: цифры и факты
- «Обучающий воркшоп» — теория (2 минут) + практика (5 минут),​
задания для участников, чек-листы
- «Доклад на конференции» — интрига, проблема отрасли,​
3 инсайта, кейсы, выводы, призыв к действию
- «Продающая презентация» — боль клиента, решение,​
преимущества, соцдоказательство, оффер

При выборе шаблона автозаполняется формат и добавляется ​
скрытая инструкция к промпту. Можно не выбирать шаблон

Копировать

### Шаг 5: Добавление экспорта

Структура бесполезна, если ее нельзя забрать. Добавим экспорт

Промпт для Lovable:

Добавь экспорт структуры презентации:

1. «Копировать все» — структура в буфер обмена в формате:

Слайд 1: [Заголовок] / — Тезис / Заметки: [текст]

1. «Скачать TXT» — файл presentation-outline.txt
1. «Скачать Markdown» — файл .md с заголовками и списками
1. «Копировать слайд» — кнопка на каждой карточке

Кнопки экспорта — панель над карточками

Уведомление «Скопировано!» при успехе

Копировать

Почему текстовый формат

Текст и Markdown открываются везде. Легко вставить в Google Slides, ​
PowerPoint или Notion. Универсальность важнее красоты.

Ожидаемый результат: Копирование в один клик. ​
Файлы скачиваются с понятными именами

### Что дальше

Приложение работает. Идеи для развития:

●​ Экспорт в PDF — оформленный документ с брендом спикера

●​ Библиотека шаблонов — 20-30 шаблонов под разные ниши и события

●​ Несколько языков — генерация на английском, испанском и других

●​ Командный доступ — несколько спикеров в одном аккаунте

●​ История генераций — все структуры сохраняются с поиском

●​ Режим репетиции — таймер показывает слайды с учетом времени

●​ Экспортируйте и используйте для подготовки выступления
