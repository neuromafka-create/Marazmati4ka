# Что такое вайб-кодинг

Вайб-кодинг — это новый подход к разработке, где код помогает писать
искусственный интеллект, а не человек.

Вы описываете задачу словами, а нейросеть собирает проект: создаёт
структуру, пишет код, исправляет ошибки и помогает протестировать
результат.

Пример:

«Сделай страницу с калькулятором стоимости и кнопкой отправки
заявки».

Через пару минут Вы уже видите работающий прототип.

# Где создаются проекты

Все вайб-проекты рождаются в специальных онлайн- или локальных средах.

Это как «дом» для Вашего AI-помощника — место, где он пишет, тестирует и
показывает результат.

Давайте разберёмся, какие инструменты реально работают и чем отличаются.

## Page 3

# Cursor

База для старта

Что это:
Редактор на основе Visual Studio Code с интегрированным AI.
Вы пишете задачу на обычном языке — и редактор сам создаёт нужный код.

Как работает:

Устанавливается на Windows, macOS и Linux.

Поддерживает языковые модели ChatGPT, Claude, DeepSeek и др.

Можно писать, запускать и проверять проект в одном окне.

Плюсы:

Понятный интерфейс для новичков.

Бесплатный тариф (ограниченный).

Платный план Pro — около $20 в месяц.

Минусы:

Без платного плана часть функций ограничена.

Требует базового понимания, как устроены файлы проекта.

## Page 4

# Windsurf

Лёгкий режим

Что это:
Упрощённая среда для генерации и редактирования кода с AI.
Создана как более «человечный» аналог Cursor.

Как работает:

Приложение устанавливается на компьютер и сразу готово к работе.

Можно просто писать: «Добавь форму обратной связи» — и редактор
сам её создаст.

Плюсы:

Минималистичный интерфейс.

Бесплатный тариф и подписка от $15 в месяц.

Подходит для коротких проектов, обучения и экспериментов.

Важно:
Интеграция с OpenAI пока в стадии развития.

## Page 5

# Kilo Code

Для тех, кто хочет гибкости

Что это:
Расширение для VS Code, которое помогает строить продвинутые
проекты с AI.
Подходит, если Вы уже пробовали Cursor и хотите больше контроля.

Как работает:

Добавляется как плагин.

Есть режимы для проектирования, написания и отладки кода.

Поддерживает ChatGPT, Claude, DeepSeek и локальные модели.

Плюсы:

Гибкость и высокая точность.

Можно подключать базы данных и API.

Бесплатно для установки, платные токены у моделей.

Минусы:

Требует немного больше терпения и внимания к деталям.

## Page 6

# Replit

Всё прямо в браузере

Что это:
Онлайн-редактор, где Вы можете писать и запускать код без установки
программ.
Есть встроенные AI-помощники.

Как работает:

Заходите на replit.com.

Выбираете шаблон — сайт, бот, приложение.

Нажимаете Run — проект запускается на сервере Replit.

Плюсы:

Работает в браузере (даже с телефона).

Есть бесплатный план.

Подходит для первых проб и мини-проектов.

Минусы:

Работает медленнее, чем локальные IDE.

Некоторые функции AI доступны только по подписке.

## Page 7

# n8n

Автоматизация без кода

Что это:
Визуальный инструмент для автоматизации процессов.
Позволяет соединять разные сервисы между собой: заявки, таблицы,
письма, Telegram.

Как работает:

Вы добавляете блоки действий (например: Google Sheets и Telegram).

Соединяете их стрелками — и всё работает автоматически.

Плюсы:

Полностью без кода.

Бесплатно и можно установить локально.

Хорошо интегрируется с Cursor и Kilo Code.

Минусы:

Требует немного времени, чтобы понять логику цепочек.

# Перед стартом

Начните с Cursor — это оптимальная точка входа.

Экспериментируйте и сохраняйте удачные промты.

Проверяйте сгенерированный код перед публикацией.

Не передавайте AI личные данные или ключи API.

Когда почувствуете уверенность — добавьте n8n для автоматизации.
