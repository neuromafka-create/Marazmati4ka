🎯 ЧАСТЬ 1. FEATURE CREEP: ГЛАВНЫЙ ВРАГ ВАЙБКОДЕРА

MVP (Minimum Viable Product)- это минимально жизнеспособный продукт.

Главная ошибка новичков: они просят у нейросети сразу создать "убийцу Airbnb с 3D-графикой, крипто-оплатой и встроенной соцсетью". 
Что происходит дальше?
1. ИИ напрягается.
2. Пишет 4000 строк сложнейшего кода.
3. Ломается пополам. Вылетает фатальная ошибка, экран остается пустым, у вас опускаются руки.

Секрет индустрии: мы собираем приложения по крошечным кирпичикам. 

Ваша идея огромна, но сегодня нам нужна только визуальная оболочка. Если вы делаете приложение для учета чеков- пусть сегодня оно просто выводит три красивых (выдуманных) чека на экран.
• Без баз данных.
• Без доступа к реальной камере.
• Без сложного бэкенда. 

Просто идеальная "картинка", которая уже кликается. 

━━━━━━━━━━

💻 ЧАСТЬ 2. КАК ЗАСТАВИТЬ ИИ СДЕЛАТЬ ИДЕАЛЬНУЮ ПЕРВУЮ ВЕРСИЮ?

Открываем наш проект в среде разработки, в которой уже начали. Сейчас в папке лежит только наш вчерашний SPEC.md, (а некоторые даже не удержались и пошли дальше).

Пишем агенту наш коронный итеративный промпт. Скопируйте его:

Команда для ИИ:
"Привет! Я хочу начать разработку. Изучи файл @SPEC.md для понимания контекста. Наша цель на сегодня- построить MVP. 
⚡ ШАГ 1. Создай только базовую визуальную структуру главного экрана.
⚡ ШАГ 2. Не подключай реальные базы данных и API! Используй mock (фейковые) данные (напиши их прямо в коде), чтобы я сейчас мог просто потрогать интерфейс.
⚡ ШАГ 3. Сделай дизайн премиальным и современным, строго следуя нашей Design System из спецификации. Жду результат!"

Вы откидываетесь на спинку кресла. Агент самостоятельно создаст файлы, простроит структуру компонентов, наполнит их "рыбным" текстом и выдаст вам результат, который можно потрогать в браузере.

Я написала для вас глубокую пошаговую шпаргалку по созданию интерфейсов без нервов- ищите её в прикрепленном файле "Гайд 3. Строим MVP".

━━━━━━━━━━

🛠 ЧАСТЬ 3. ОШИБКИ НЕИЗБЕЖНЫ!

В тот момент, когда агент выдаст вам первый код, вы можете увидеть красный экран ошибки. Без паники! 

В вайбкодинге всё решает правильная обратная связь. Вам не нужно вчитываться в красные логи. 
Что делать: просто скопируйте текст ошибки или сделайте скриншот и отправьте агенту:

Команда для ИИ:
"У нас упала ошибка: \[текст\]. Пожалуйста, проанализируй логику и исправь её, не ломая общую архитектуру."

Агенты потрясающе справляются с самоисцелением (Self-Healing). Они сами проанализируют свой же код и перепишут его.

📌 ЗОЛОТОЕ ПРАВИЛО MICRO-STEPS:
Когда базовый интерфейс заработал, никогда не просите агента: "А теперь поменяй цвет кнопки, добавь новую страницу профиля, сложную анимацию и переведи всё на китайский". 

Просите ровно одно изменение за раз:
1. ✅ "Сделай анимацию карточек". Проверили. Работает.
2. ✅ "Теперь добавь страницу профиля". Проверили. Работает.

Это 100% гарантия успешного вайбкодинга без критических откатов.
