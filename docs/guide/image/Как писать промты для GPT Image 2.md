📐 Формула из 7 блоков

1. ТИП КАДРА
   что это: фото / мокап / иллюстрация / скриншот / постер

2. СУБЪЕКТ
   кто или что в центре + 2-3 конкретных детали

3. СЦЕНА
   где, когда, что вокруг, деталь фона

4. СВЕТ
   источник + характер (жёсткий/мягкий/смешанный)

5. КАМЕРА
   объектив, ракурс, дистанция, глубина резкости

6. ТЕКСТ  (если нужен на картинке)
   в "двойных кавычках" + шрифт + позиция

7. ФОРМАТ
   соотношение сторон: 1:1, 9:16, 3:2, 16:9

Порядок важен. Первые 50 слов модель читает 
с наибольшим весом — клади туда главное.

✏️ Главный хак: текст в кавычках

Модель теперь пишет русский читаемо. Но только 
если оформить правильно:

→ точный текст — в "двойных кавычках"
→ акценты — КАПСОМ
→ шрифт и позицию — явно словами
→ в конце добавь: verbatim, no substitutions

Пример:
Баннер с заголовком "ЧЁРНАЯ ПЯТНИЦА" 
жирным санс-серифом в верхней трети, 
подзаголовок "скидки до 70%" курсивом ниже, 
белый текст на красном, verbatim.

Работает и на русском, и на английском.

🔧 Паттерн для правок

Забудь «сделай лучше». Используй схему:

  Change: [что меняем]
  Preserve: [лицо/позу/свет/фон — что не трогаем]
  Constraints: [чего точно не должно быть]

Пример на практике:
  Change: замени фон на белую студию
  Preserve: лицо, позу, костюм, освещение модели
  Constraints: без теней на фоне, без ретуши,
               без смены пропорций

Теперь модель не перерисует полкартинки из любви 
к искусству.
