🚀 ИНСТРУКЦИЯ:

🔹 ШАГ 1. Подготовьте изображение

Выберите свою фотографию.
Загрузите её в новый диалог ChatGPT.
Попросите ChatGPT:
«Опиши максимально подробно внешность человека на фото. Не указывай выражение лица».
Это нужно для создания узнаваемых стикеров.

🔹 ШАГ 2. Сформулируйте запрос (промпт) к нейросети
Используйте шаблон:
 Предложи концепцию для 5 стикеров в разных эмоциях, с разными фразами для ниши [вставь нишу].
Каждый стикер должен отражать конкретную эмоцию (например, грусть, радость, удивление, усталость, энтузиазм) и содержать короткую фразу, типичную для специалиста этой ниши.
Используй внешность — [опиши внешность].
Все стикеры должны быть выполнены в едином мультяшном стиле (например, Disney).
Цвет надписи — неоново-голубой.
Формат — квадратный стикер на прозрачном фоне.
В каждом стикере должна быть атрибутика, связанная с нишей.
Человек на стикерах должен быть узнаваем.
Все стикеры должны различаться по эмоции и фразе, но быть выполнены в едином стиле.
⚠️ Лучше просить один стикер за раз, иначе возникают баги.

🔹 ШАГ 3. Генерация стикера

Убедитесь, что:
Формат квадратный (512×512 или близко).
Фон прозрачный.
Человек на стикере — узнаваем.
Есть нужная эмоция и фраза.


🔹 ШАГ 4. Проверка и правки

Если стикер получился с ошибками:
Можете подредактировать в Paint, например, дорисовать недостающий элемент.
Если слишком много текста — сократите надпись.

🔹 ШАГ 5. Изменение размера (если нужно)

Перейдите на сайт: iloveimg.com/resize-image
Загрузите изображение.
Установите: 512 x 512, прозрачный фон должен сохраниться.
Скачайте отредактированное изображение.

🔹 ШАГ 6. Загрузка в Telegram

Перейдите в Telegram-бот: @Stickers.
Нажмите /start, затем «Создать новый набор».
Введите название набора (на английском).
Загрузите изображение.
⚠️ Уберите галочку «сжать изображение» при загрузке.
Укажите эмодзи, соответствующий стикеру (например, 🧠 или 🚀).
Добавьте остальные стикеры по одному.
Нажмите «Опубликовать набор».
