Нейросети без ВПН в России (ChatGPT, Gemini, Claude, Sora, VEO и другие)
НЕЙРО ПРОФИТ • 20 февраля в 14:55
Для доступа к зарубежным нейросетям, таким как ChatGPT, Gemini и другим, в России можно использовать DNS сервер Xbox. Сервис подменяет адреса, проксируя трафик для обхода ограничений IP-адресов. DNS безопасен: он шифрует запросы (DoH, DoT), а данные остаются защищены HTTPS. В статье описана настройка DNS на Windows, macOS, Android, iOS и роутерах.
Cocoon AI Summary
Доступ к многим зарубежным сервисам в России ограничен не из-за блокировок регуляторов, а вследствие санкционной политики самих компаний. ChatGPT, Gemini, Spotify, Claude и другие отслеживают ваш IP-адрес и ограничивают вход. Чтобы решить проблему - будем использовать DNS сервер Xbox. Изначально он был запущен для помощи геймерам — они не могут получить доступ к магазину игр без обхода блокировок со стороны Microsoft

Как это работает:
Обычно сервисы блокируют доступ из России по IP. DNS решает это просто: при попытке зайти на «закрытый» сайт он подменяет адрес и направляет трафик через прокси, в итоге сайт открывается без ограничений. А обычные сайты — например госуслуги, банки, Google работают напрямую. DNS не обходит блокировки Роскомнадзора!



Безопасно ли?
Да, если понимать, как это работает: DNS видит, какой сайт вы открыли, но не страницу внутри. Сейчас все сайты используют HTTPS, поэтому данные, пароли и карты остаются под защитой. Так же XBox DNS шифрует запросы (DoH, DoT), так что даже провайдер не узнает, куда вы заходите.


Настройка на Windows
Шаг 1. Откройте «Параметры» → «Сеть и Интернет» → Wi-Fi или Ethernet (в зависимости от типа вашего подключения).

Шаг 2. Пролистайте ниже и найдите «Назначение DNS-сервера» → «Изменить» → «Вручную»

Шаг 3. Включите параметр IPv4 и заполните пункты следующим образом:

Предпочтительный DNS-сервер — 176.99.11.77
DNS по протоколу HTTPS — Включено (ручной шаблон)
Шаблон DNS по протоколу HTTPS — https://xbox-dns.ru/dns-query
Дополнительный DNS-сервер — 80.78.247.254
DNS по протоколу HTTPS — Включено (ручной шаблон)
Шаблон DNS по протоколу HTTPS — https://xbox-dns.ru/dns-query
Шаг 4. Нажмите «Сохранить».



Настройка в браузере
Шаг 1. В Chrome, Edge, Яндекс откройте Настройки → Конфиденциальность и безопасность → Безопасность → Дополнительные настройки или Защита соединения.

Шаг 2. Вместо поставщика услуг DNS по умолчанию выберите «своего поставщика услуг DNS».

Шаг 3. В появившемся поле введите https://xbox-dns.ru/dns-query



Настройка на iOS и macOS
Шаг 1. Скопируйте адрес https://xbox-dns.ru/ios/xbox-dns.mobileconfig.

Шаг 2. Откройте эту ссылку в браузере Safari.

Шаг 3. Разрешите сайту загрузить профиль конфигурации.

Шаг 4. Откройте Настройки устройства → Основные → VPN и управление устройством.

Шаг 5. Выберите загруженный профиль XBox DNS (DoH). Нажмите «Установить» и введите пароль от устройства.



Настройка на Android
Шаг 1. Откройте «Настройки» → «Сеть и Интернет» → «Частный DNS-сервер».

Шаг 2. Выберите настройку «Имя хоста поставщика частного DNS-сервера».

Шаг 3. Введите xbox-dns.ru и выберите «Сохранить».

На разных смартфонах названия пунктов могут отличаться. Можете в настройках в поиске просто ввести "DNS"


Настройка на роутере
У разных роутеров свои настройки, но в общих чертах инструкция выглядит так:

Шаг 1. Откройте настройки своего роутера.

Шаг 2. Найдите раздел, отвечающий за установку соединения. Выберите «Настроить DNS вручную» (или пункт с похожим названием).

Шаг 3. Пропишите следующие настройки (просто IP, DNS через TLS или DNS через HTTPS в зависимости от того, какой вариант поддерживает ваш роутер):

Основной IPv4: 176.99.11.77.
Дополнительный IPv4: 80.78.247.254.
Основной IPv6: 2a00:f940:2:4:2::5d1b.
Дополнительный IPv6: 2a00:f940:2:4:2::21ed.
DNS-over-TLS: xbox-dns.ru.
DNS-over-HTTPS: https://xbox-dns.ru/dns-query.
