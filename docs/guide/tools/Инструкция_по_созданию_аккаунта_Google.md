## Page 5

| Вариант 1: Регистрация через браузер (Шаг 3-6) Шаг 3 Ввод личной информации Введите дату рождения (рекомендуется возраст 21+ год) и выберите пол. Нажмите кнопку "Далее". Шаг 4 Выбор адреса Gmail Выберите предложенный вариант адреса или создайте свой (например, studentneuro9). Нажмите "Далее". Шаг 5 Создание пароля Придумайте надежный пароль длиной не менее 8 символов, включающий буквы, цифры и специальные символы. Нажмите "Далее". Шаг 6 Подтверждение номера телефона Выберите "Россия" в выпадающем списке и введите действующий номер телефона. Дождитесь SMS с кодом и введите его в соответствующее поле. Важно: Если код не приходит на российский номер, переходите к Варианту 2 регистрации. Made with Genspark |   |   |   |

## Page 7

| Дополнительные настройки аккаунта : После создания аккаунта необходимо выполнить дополнительные шаги для его настройки и защиты 1 Вход на сайт аккаунтов Google Перейдите на сайт https://accounts.google.com/ Введите свой новый email и пароль для подтверждения доступа. 2 Настройка резервных данных На следующем экране после входа выберите «Не сейчас». При запросе резервных данных предпочтительнее указать адрес электронной почты , а не номер телефона. Вы можете использовать любой действующий email-адрес, включая российский. 3 Пропуск добавления домашнего адреса На следующей странице на вопрос о добавлении домашнего адреса нажмите «Пропустить» . После выполнения этих шагов ваш аккаунт Google будет полностью настроен и готов к использованию. Рекомендуется сразу сохранить данные для входа в надежном месте. Made with Genspark |   |   |   |
