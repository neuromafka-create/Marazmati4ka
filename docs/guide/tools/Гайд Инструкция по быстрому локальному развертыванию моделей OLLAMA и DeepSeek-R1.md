## Page 11

## Типичная проблема,
## которая может возникнуть

## и способ ее решения

Проблема:

Error: llama runner process has terminated: error loading
model: unable to allocate CUDA_Host buffer

Причина:

Недостаточно видеопамяти на вашем устройстве.

Решения:

Попробуйте запустить модель меньшего размера.

Используйте режим CPU при запуске (скорость работы
может снизиться):

ollama run deepseek-r1:7b --cpu
