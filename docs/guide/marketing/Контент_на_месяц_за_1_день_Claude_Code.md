# Изучи аудиторию — это основа всего

Большинство пропускает этот шаг. Поэтому их контент звучит одинаково и ни про кого.
Ресёрч — это 2 часа, которые экономят 20 часов плохой работы.

## 1.1 Кто твоя аудитория

Перед тем как дать Claude хоть один промпт на контент, нужно загрузить в него
понимание аудитории. Не «женщины 25–40», а живые люди с конкретными болями и
желаниями.

ПРОМПТ: Аудиторный портрет

Ты — стратег по контенту. Я хочу, чтобы ты составил детальный портрет моей аудитории.
Ниша: [впиши свою нишу] Мой продукт/услуга: [опиши кратко] Платформы где я
присутствую: [Telegram / Instagram / YouTube] Составь портрет по формату: — КТО ЭТО:
демография, образ жизни, контекст — ТОП-5 БОЛЕЙ: что не даёт спать, что бесит, чего
боятся — ТОП-5 ЖЕЛАНИЙ: мечты, цели, к чему стремятся — КАК ОНИ ГОВОРЯТ: язык, сленг,
типичные фразы (не маркетинговые!) — ЧТО УЖЕ ПРОБОВАЛИ и почему не сработало — КАКОЙ
КОНТЕНТ их реально зажигает (форматы, темы, тон) Будь конкретным. Никаких общих
слов. Думай как человек, который 3 года в этой аудитории.

## 1.2 Что делают другие в твоей теме

Дай Claude ссылки или описания 3–5 конкурентов. Задача — не скопировать, а найти
пробелы: о чём они НЕ говорят, где у них слепые пятна.

ПРОМПТ: Анализ конкурентов

Проанализируй контент-стратегию моих конкурентов: Конкурент 1: [название/ссылка] —
[кратко опиши их подход] Конкурент 2: [название/ссылка] — [кратко опиши их подход]
Конкурент 3: [название/ссылка] — [кратко опиши их подход] Определи: 1. ОБЩИЙ
ПАТТЕРН: что делают все — это значит аудитория ждёт этого как базу 2. ПРОБЕЛЫ:
темы/форматы/углы зрения, которые никто не покрывает 3. СЛАБЫЕ МЕСТА: где они
проигрывают (тон, глубина, практичность) 4. МОИ ВОЗМОЖНОСТИ: 5 конкретных тем, где я
могу выделиться Думай как инвестор, который ищет незанятую нишу.

актуальные тренды в твоей нише за последние 30 дней.

# Стратегия — структура месяца

## 2.1 Основные темы канала

Контент-тема — это тема, вокруг которой крутится несколько единиц контента. Обычно
3–5 темаов на нишу. Они дают структуру и не дают тебе метаться.

ПРОМПТ: Основные темы канала

[Вставь сюда контекстный пакет из Фазы 1] На основе аудиторного портрета и анализа
конкурентов определи 4 темаа для моего канала. Для каждого темаа: — НАЗВАНИЕ и суть
(1 предложение) — ПОЧЕМУ это важно именно моей аудитории — 5 примеров тем в рамках
этого темаа — ФОРМАТЫ, которые лучше всего работают под этот тема — ДОЛЯ в
контент-плане (в % от всего контента) Важно: темы должны балансировать между
ОБРАЗОВАТЕЛЬНЫМ, РАЗВЛЕКАТЕЛЬНЫМ и ПРОДАЮЩИМ контентом.

## 2.2 Твой авторский голос

Это самый важный промпт в системе. Он описывает твой голос — и используется в
начале каждой производственной сессии. Без него Claude пишет «как ИИ».

ПРОМПТ: Твой авторский голос

Помоги мне создать описание моего авторского голоса для контента. Ответь на мои
вопросы: — Я пишу как [официально/неформально/разговорно]? — Мой тон:
[экспертный/дружеский/провокационный/вдохновляющий]? — Что я никогда не говорю?
(запрещённые слова/фразы) — Примеры моих лучших постов: [вставь 2-3 примера] На
основе этого создай описание голоса длиной 200–250 слов, которое я буду давать тебе
как инструкцию перед каждой генерацией контента.

## 2.3 Контент-план на месяц

ПРОМПТ: Контент-план

[Контекстный пакет] [Описание голоса] [4 темаа] Создай контент-план на 30 дней для
[Telegram / Instagram / YouTube — выбери нужное]. Формат плана: — Неделя 1–4 с
конкретными темами под каждый день — Для каждого поста: ТЕМА | ФОРМАТ | СТОЛП |
КРЮЧОК (1 предложение) — Распредели: 40% обучение, 30% истории/личное, 20% польза,
10% продажи — Учти: понедельник и среда — пик активности, пятница — дай лёгкое Выведи
в виде таблицы. Темы должны быть конкретными, не абстрактными.

# Производство — батчи по форматам

Главное правило фазы 3: один формат — одна сессия. Не переключайся между
форматами. Сначала все посты, потом все сценарии, потом все карусели.

⚡ Почему батчи, а не по одному? Claude держит стиль лучше, когда пишет серию
однотипных единиц подряд. Ты сохраняешь контекст и не теряешь темп.

## 3.1 Блок: Посты для Telegram

ПРОМПТ: Серия постов Telegram

[Контекстный пакет] [Описание голоса] Напиши серию из 8 постов для Telegram по этим
темам: [Вставь 8 тем из контент-плана] Требования к каждому посту: — Длина: 800–1200
символов — Первые 2 строки = крючок (человек видит только их в превью) — Структура:
крючок → боль/история → суть → вывод → CTA или вопрос — Используй форматирование
Telegram: **жирный**, _курсив_, эмодзи — умеренно — Заканчивай вопросом к аудитории
или призывом к действию — НЕ начинай посты одинаково Пиши все 8 подряд, без пауз и
объяснений.

## 3.2 Блок: Reels/Shorts сценарии

ПРОМПТ: Сценарии для коротких видео

[Контекстный пакет] [Описание голоса] Напиши 4 сценария для Reels/Shorts по темам:
[Вставь 4 темы] Формат каждого сценария: — КРЮЧОК (первые 3 секунды): что
говорим/показываем — ТЕКСТ ДЛЯ СУБТИТРОВ: построчно, 5–8 слов в строке —
ХРОНОМЕТРАЖ: 45–60 секунд — ПРИЗЫВ В КОНЦЕ: что зритель должен сделать — B-ROLL
ПОДСКАЗКИ: что снимать на фоне Крючок должен останавливать скролл. Первые 3 секунды
- единственное что важно.

## 3.3 Блок: Карусели Instagram

ПРОМПТ: Карусели (структура слайдов)

[Контекстный пакет] [Описание голоса] Создай структуру 3 каруселей для Instagram по
темам: [Вставь 3 темы] Для каждой карусели: — ОБЛОЖКА (слайд 1): заголовок +
подзаголовок (не более 8 слов в заголовке) — СЛАЙДЫ 2–7: заголовок слайда + 2–3
ключевых тезиса — ФИНАЛЬНЫЙ СЛАЙД: CTA + что сохранить/куда идти дальше — ПОДПИСЬ К
ПУБЛИКАЦИИ: 3–4 строки + хэштеги Карусели должны давать ценность на каждом слайде.
Читатель должен хотеть листать.

# Финализация — твоя рука, не ИИ

90% авторов публикуют контент как есть после генерации. Именно поэтому он звучит
как ИИ. Финализация — 1–2 часа, которые делают разницу.

## 4.1 Редактура: добавляем живость

ПРОМПТ: Живой голос

Отредактируй этот текст так, чтобы он звучал как живой человек, а не ИИ: [Вставь
сгенерированный текст] Что нужно сделать: — Убери все клише: 'в современном мире',
'важно отметить', 'следует подчеркнуть' — Добавь 1–2 конкретных личных детали (можно
оставить плейсхолдер [твоя история]) — Сделай первое предложение сильнее — оно
должно останавливать — Убери всё, что звучит как инструкция или лекция — Сохрани
смысл, измени форму

## 4.2 Контент-календарь: раскладка по датам

ПРОМПТ: Контент-календарь

Вот мой список готового контента на месяц: [Список тем и форматов] Создай
публикационный календарь: — Учти дни высокой активности (пн, ср, чт — для сложного;
пт, вс — для лёгкого) — Чередуй форматы: не 3 поста подряд, потом видео — Размести
продающий контент после серии из 3–4 полезных — Выдай в формате таблицы: Дата | Тема
| Формат | Платформа | Время публикации Платформы: [Telegram / Instagram / YouTube —
нужное оставить]
