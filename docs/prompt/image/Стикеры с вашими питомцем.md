# [Стикеры с вашими питомцем](https://t.me/c/3256552589/120)

Для создания таких фото в Telegram используйте ChatGpt Image. Переходи в бота, (https://t.me/neirobanana_bot?start=bananaprompt) жми /start -> выбор модели -> ChatGpt Image -> назад -> сгенерировать.

❗️Важно: Если Telegram не принимает большой промпт, то сначала отправьте фото и уже следующим сообщением текст.

```txt
Создай набор из 10 Telegram-стикеров на основе загруженного фото моего питомца. Сохрани все уникальные черты внешности: окрас, форму морды, глаз, ушей, шерсти и общий характер.
Стикеры должны выглядеть как профессиональный Telegram
sticker pack.
Стиль:
* Милый, выразительный, мемный, современный.
* Чистый белый контур вокруг персонажа.
* Прозрачный фон.
* Яркие эмоции с преувеличенной мимикой.
* Качественная цифровая иллюстрация.
* Единый художественный стиль для всего набора.
* Формат Telegram sticker:
* Простая анимация для каждого стикера: моргание, покачивание, подпрыгивание, виляние хвостом, дрожание от смеха, появление сердечек или других небольших эффектов.
Создай следующие 10 эмоций и реакций:
1. Радость — питомец широко улыбается, счастливый, сияющие
2. Смех — громко смеётся, глаза прищурены, слёзы от смеха.
3. Любовь — глаза-сердечки, вокруг летают сердечки.
4. Грусть — опущенные уши, большие грустные глаза, маленькая
5. Злость — нахмуренные брови, недовольное выражение.
6. Удивление - широко открытые глаза и рот.
7. Лайк - показывает жест "лайк" или уверенное согласие.
8. Шок — сильно удивлён, шерсть дыбом, эффект вспышки.
9. Сонливость — зевает, прикрытые глаза, маленькие "Zzz".
10. Празднование — в конфетти, радостно танцует или прыгает.
Требования:
* Каждый стикер должен быть отдельным кадром набора.
* Персонаж всегда должен быть легко узнаваем как питомец с фотографии.
* Максимально выразительные эмоции, характерные для популярных Telegram-стикерпаков.
* Без текста на стикерах.
* Высокая детализация, профессиональное качество, готово для публикации в Telegram.
```
