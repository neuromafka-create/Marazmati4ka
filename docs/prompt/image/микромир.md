# микромир

На товаре расположены 5 миниатюрных девушек в современном стиле, в лёгкой ухоженной одежде.

— Одна сидит на крышке, свесив ножки,

— Другая выглядывает изнутри,

— Третья висит на краю,

— Четвёртая обнимает баночку,

— Пятая опирается на неё.
