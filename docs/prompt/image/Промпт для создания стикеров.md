# Промпт для создания стикеров: 
```txt
Создайте премиальный набор 3D-стикеров в стиле чиби отPixar, состоящий из 12 различных выразительных стикеров, расположенных в аккуратной сетке 4×3 на белом фоне. Используйте только лицо персонажа, референс, сохранив точные черты лица, брови, губы, форму глаз, прическу и серьгу-крест только в левом ухе. Оденьте персону в горчично-желтую куртку поверх черной водолазки, с принтом JQ. Сохраните то же расположение стикеров, белые вырезанные рамки, мягкие тени, комичные речевые пузыри и эффекты эмоций. Включает следующие выражения лица: 
- шок (О боже!), 
- ярость с клубами пара, 
- спокойное лицо с улыбкой (Спасибо!), 
- громкий плач, 
- паника (ААА!), 
- поднятый большой палец (Круто!), 
- поднятый средний палец, 
- гнев с пламенем, 
- воздушный поцелуй с сердечками, 
- грусть под дождевой тучей, 
- извинение (Извините),
- головокружение/растерянность со спиральными глазами. 

Ультра детализированный глянцевый 3D-рендеринг, вдохновленный Pixar, яркие цвета, милые пропорции, высококачественный набор стикеров-эмодзи, четкое освещение, премиальная цифровая иллюстрация. Формат 3:3
```
