ЭТАП 3. СТРАТЕГИЯ ЛИЧНОГО БРЕНДА

Выдай готовую стратегию.

1. ПОЗИЦИОНИРОВАНИЕ

Сформулируй:
— Позиционирование в одном предложении
Кто человек, для кого он, какую проблему решает, каким способом.
— Расширенное позиционирование
2–4 предложения: чем эксперт полезен, в чём его сила, почему ему можно доверять.
— УТП
Почему выбрать именно этого человека, а не другого эксперта.
— Антипозиционирование
Кем человек точно НЕ является.
Например: не инфоцыган, не душный теоретик, не эксперт “обо всём”, не продавец волшебной таблетки.
— 3 главных посыла бренда
Что аудитория должна запомнить после 5–7 касаний.
— 3 доказательства экспертности
Факты, опыт, кейсы, подход, результаты, путь, наблюдения.
— Фраза для шапки профиля
Короткая, понятная, без воды.
— Короткое описание “о себе”
Для Telegram/Instagram/VK/сайта.

2. ПРОДУКТ И МОНЕТИЗАЦИЯ

Определи:
— Что лучше продавать через личный бренд сейчас

— Какой оффер можно сформулировать
— Как аудиторию переводить от контента к заявке
— Какие темы должны прогревать к покупке
— Что не стоит продавать прямо сейчас и почему

Если продукта пока нет — предложи 2–3 варианта простого первого продукта.

3. КОНТЕНТ-СТРАТЕГИЯ

Сформируй:
— 5 основных рубрик контента
Для каждой рубрики укажи:

— Контент-матрицу

1. Экспертный контент
2. Личный контент
3. Продающий контент
4. Провокационный/мнение
5. Кейсы и разборы

1. Тему
2. Формат
3. Первый хук
4. Главный тезис
5. Цель поста: охват / доверие / продажа / вовлечение / прогрев

Темы должны быть реальными, а не заглушками.

— 5 идей для сильных постов
Сформулируй так, чтобы человек мог сразу сесть и написать.

— 3 идеи для вирусного/репостного контента
С учётом ниши, характера и аудитории.

4. PR-СТРАТЕГИЯ

Предложи:
— Где эксперту нужно появляться
Типы площадок: каналы, подкасты, СМИ, эфиры, сообщества, мероприятия, коллаборации.
— 5 идей для коллабораций
Не абстрактно “сделать эфир”, а с кем, на какую тему и зачем.

Темы должны усиливать позиционирование.
— Шаблон сообщения для предложения коллаборации
Короткий, человеческий, без канцелярита.
— Как использовать чужую аудиторию без ощущения навязчивости.

5. ВИЗУАЛЬНАЯ СТРАТЕГИЯ

Опиши:

Фото, видео, сторис, обложки, аватар, оформление.

Цвета, настроение, одежда, фон, детали, подача, мимика, ракурсы.

— Как выглядеть дороже/экспертнее без дорогой съёмки
