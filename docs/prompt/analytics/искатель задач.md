🔥Промпт-искатель задач 
#промпт
Проанализируй сферу деятельности [ПСИХОЛОГ] и найди все задачи, которые можно автоматизировать с помощью ИИ.

Раздели задачи по категориям:
1. Повторяющиеся (что делается одинаково каждый день)
2. Времязатратные (что занимает 2+ часа) 
3. Рутинные (что можно описать алгоритмом)
4. Творческие (где нужны идеи и варианты)

Для каждой задачи укажи:
- Сколько времени экономится
- Пример результата

Сделай вывод и покажи общее время которое может сэкономить человек ускорив все задачи с помощью нейросетей
Формат ответа: конкретно и по делу, без воды. Сделай в таблице в нашем чате. 

А после таблицы ничего не делай  и задай вопрос хочет ли пользователь разработать промпты для каждой задачи. 
Если хочет, то переходи ко второму шагу. И во втором шаге нужно разработать — промпт под каждую задачу, промпт опиши по формуле CRAFT. Только не указывай аббревиатуру и когда будешь разрабатывать промпты для решения задач, выдели их отдельным шрифтом, чтобы можно было скопировать и сразу вставить в нейросеть
