🏅Краткая версия, кто хочет быстрый результат:
Проведи комплексный анализ рынка для запуска [МОЙ ПРОДУКТ/УСЛУГА] в [СТРАНА, ГОРОД], включающий макрофакторы (pestetl), анализ конкурентов и ЦА, для выявления возможностей, рисков и формирования рекомендаций по позиционированию и стратегии входа.

🏆Продвинутая версия для тех, кто хочет реально глубокое исследование рынка.
(раскройте и скопируйте)
Сделай глубокий анализ рынка для запуска нового бизнеса, выявление возможностей/угроз, сегментация ЦА, рекомендации по позиционированию и стратегии входа.

1. Идея бизнеса:
1.1 Мой продукт/Услуга: [КРАТКО ОПИШИТЕ ВАШ БИЗНЕС/ПРОДУКТ/УСЛУГУ].
1.2 Моя география запуска: [УКАЖИТЕ КОНКРЕТНЫЙ РЕГИОН/ГОРОД/СТРАНУ].
1.3 Моя целевая аудитория: [УКАЖИТЕ СВОЮ ЦА, если знаете.]

2. Запросы по анализу:
- Макроанализ (PESTEL): Оцените политические/правовые, экономические, социальные/культурные и технологические факторы, влияющие на мой рынок. Включите инфляцию, доходы населения, изменение потреб. предпочтений, развитие релевантных технологий.

Отрасль и Конкуренты:
- Размер/Рост: Текущий размер и прогнозируемые темпы роста моего рынка. Драйверы роста/сдерживающие факторы.
- Конкуренция: Идентифицируйте 5-7 ключевых конкурентов в моей географии. Для каждого: доля рынка (если есть), продукты, цены, стратегии продвижения, SWOT-анализ.
- Барьеры/Силы: Оцените барьеры входа/выхода, силу поставщиков/покупателей, угрозы заменителей/новых игроков.
- Отраслевой SWOT: Сделайте SWOT-анализ для всей отрасли.

Целевая Аудитория (ЦА):
- Доработай или расширь профили моей ЦА: Демографический (возраст, пол, доход, образование) и психографический (ценности, интересы, стиль жизни) портрет моей ЦА
- Потребности/Поведение: Их проблемы, "боли", мотивации, каналы информации, готовность платить, поведенческие барьеры/драйверы применительно к моему продукту.

3. Требуемый результат (инсайты и рекомендации):
- Сегментация: Предложите потенциальные сегменты ЦА с оценкой их привлекательности.
- Позиционирование: Идеи для УТП и стратегии позиционирования, чтобы выделиться на рынке.
- Маркетинг: Рекомендации по наиболее эффективным маркетинговым каналам и ценовым стратегиям.
- Продукт: Какие особенности продукта/услуги будут наиболее ценны для ЦА.
- Риски/Ниши: Выявите потенциальные риски и предложите способы их минимизации. Укажите неохваченные ниши.

4. Формат вывода: Структурированный отчет с заголовками, маркированными списками и краткими резюме.
