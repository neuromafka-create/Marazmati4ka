Вот готовый **мастер-промпт**, оптимизированный для генерации изолированных визуальных копий. Он содержит чёткие технические ограничения, шаги валидации и готов к копированию в любой продвинутый AI-агент.

```text
РОЛЬ: Ты — senior frontend-разработчик, специализирующийся на точном клонировании веб-страниц в полностью изолированном виде на чистом HTML/CSS/JS без фреймворков.

ВХОДНЫЕ ДАННЫЕ: URL главной страницы сайта заказчика: [ВСТАВЬ_URL]

ЗАДАЧА: Сгенерируй точную визуальную копию указанной страницы, полностью защищённую от влияния стилей, скриптов и глобального окружения родительского сайта-портфолио. Код должен быть самодостаточным, валидным и готовым к встраиванию в контейнер.

🔒 КРИТИЧЕСКИЕ ТРЕБОВАНИЯ ИЗОЛЯЦИИ:
1. УНИКАЛЬНЫЙ ПРЕФИКС:
   - Сгенерируй префикс на основе домена вида: `prj_[первые_6_символов_домена]_[4_цифры]_` (пример: `prj_example_8341_`).
   - Применяй его ко ВСЕМ: классам, id, data-атрибутам, CSS-переменным, JS-функциям и переменным.
   - Оберни всю структуру в: `<div id="[ПРЕФИКС]wrapper" class="[ПРЕФИКС]wrapper" data-project="[ПРЕФИКС]">...</div>`

2. ИЗОЛЯЦИЯ СТИЛЕЙ:
   - На `#[ПРЕФИКС]wrapper` установи: `all: initial; contain: layout style paint; font-family: inherit; line-height: 1.5; color: inherit; box-sizing: border-box;`
   - Внутри wrapper примени минимальный CSS-reset только для потомков.
   - НИКАКИХ глобальных селекторов (`*`, `body`, `html`, `p`, `a`, `div` без префикса). Все правила начинаются с `#[ПРЕФИКС]wrapper` или `.[ПРЕФИКС]...`.
   - Сохрани оригинальные медиа-запросы, но ограничь их областью видимости wrapper'а.

3. ИЗОЛЯЦИЯ СКРИПТОВ:
   - Весь JS оберни в IIFE: `(function(){ 'use strict'; ... })();`
   - Запрещено: глобальные переменные, `window.xxx`, `document.querySelector` без контекста, `eval`, `innerHTML` без санитизации.
   - Все DOM-поиски только через: `const root = document.getElementById('[ПРЕФИКС]wrapper'); root.querySelector(...)`
   - События вешать только через `addEventListener`, делегирование — строго внутри root.
   - Если оригинал использует `localStorage`/`sessionStorage`, префиксируй ключи: `[ПРЕФИКС]_keyName`.

4. АССЕТЫ И РЕСУРСЫ:
   - Изображения, SVG, шрифты, фавиконки: используй абсолютные URL оригинала.
   - Если ресурс недоступен из-за CORS или блокировки, замени на placeholder с комментарием `<!-- [ASSET_FALLBACK] -->`.
   - Шрифты подключай через `@font-face` или `<link>`, но ограничивай область применения через `font-family` внутри wrapper.
   - Не подключай внешние библиотеки (jQuery, Bootstrap, GSAP и т.д.). Всё пиши вручную.

5. ФУНКЦИОНАЛЬНОСТЬ:
   - Сохрани сетку, отступы, цвета, типографику, hover/focus состояния, анимации на CSS.
   - Сложные бэкенд-зависимые элементы (формы отправки, авторизация, чаты, динамические фиды) замени на статичные заглушки или упрощённые CSS/JS аналоги. Пометь: `<!-- [SIMULATED] -->`.
   - Обеспечь базовую адаптивность (mobile ≥320px, tablet ≥768px, desktop ≥1024px) через `@media`, если она присутствовала в оригинале.

📦 ФОРМАТ ВЫВОДА:
Верни единый HTML-файл. Структура строго:
```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Демо-копия: [Название_проекта]</title>
  <style>
    /* Полный изолированный CSS */
  </style>
</head>
<body>
  <div id="[ПРЕФИКС]wrapper" class="[ПРЕФИКС]wrapper" data-project="[ПРЕФИКС]">
    <!-- Воссозданный контент -->
  </div>
  <script>
    // Полный изолированный JS в IIFE
  </script>
</body>
</html>
```
Перед кодом добавь короткий блок комментариев:
- Как встраивать
- Что симулировано
- Возможные ограничения (CORS, внешние API)
- Инструкцию по смене префикса при конфликте

✅ КРИТЕРИИ ПРИЁМКИ:
- 0% CSS-правил, выходящих за пределы `#[ПРЕФИКС]wrapper`
- JS не читает/не пишет в `window` или `document` вне контейнера
- Визуальное соответствие оригиналу ≥90%
- Код не генерирует ошибок в консоли при открытии в пустом HTML-документе
- Все классы/id/data-атрибуты начинаются с `[ПРЕФИКС]`

ШАГИ ВЫПОЛНЕНИЯ:
1. Проанализируй URL, выдели структуру, цветовую палитру, шрифты, основные блоки.
2. Сгенерируй префикс.
3. Воссоздай HTML-дерево, применяя префикс ко всем узлам.
4. Напиши CSS с жёсткой привязкой к wrapper.
5. Напиши JS в IIFE, строго ограниченный root-контейнером.
6. Проверь на конфликты, адаптивность, изоляцию.
7. Верни готовый код строго в указанном формате.

ГОТОВ? Начни генерацию для: [ВСТАВЬ_URL]
```

### 💡 Рекомендации по использованию:
1. **Вставка в сайт-портфолио:** Достаточно скопировать вывод агента и вставить его в `<div>` или `<iframe>` на вашей странице. Благодаря `all: initial` + `contain` + префиксам, стили портфолио не "протекут" в копию, и наоборот.
2. **Если AI генерирует глобальные селекторы:** Добавьте в начало промпта системную инструкцию: `СИСТЕМА: Ты обязан строго следовать формату вывода. Любое нарушение изоляции = ошибка. Перепроверь перед выдачей.`
3. **Для 100% изоляции (опционально):** Если в будущем столкнётесь с крайними случаями (например, оригинал использует `position: fixed` или `transform` относительно viewport), замените обёртку на `<template>` + `Element.attachShadow({mode: 'open'})`. Префиксы при этом можно убрать, так как Shadow DOM даёт нативную инкапсуляцию.
4. **Автоматизация:** Этот промпт легко интегрировать в n8n, Make, LangChain или простой Python-скрипт с вызовом LLM API. Просто подставляйте URL вместо `[ВСТАВЬ_URL]`.

Проверьте на 2–3 тестовых URL. Если нужно, я могу доработать промпт под конкретный стек портфолио (React, Vue, WordPress, чистый HTML и т.д.) или добавить автоматическую генерацию `data-` атрибутов для отладки.
