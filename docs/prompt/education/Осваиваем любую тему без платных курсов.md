# Осваиваем любую тему без платных курсов

В сети раскопали полезные промты, с которыми ChatGPT поможет вам стать экспертом в теме за пару дней.

Забираем:

## 1. Учеба по методу Фейнмана:
```
Объясни мне концепцию/тему [НАЗВАНИЕ ТЕМЫ], так, будто мне 10 лет. Используй самые простые метафоры и аналогии из реальной жизни.
```

## 2. Пошаговая дорожная карта (Roadmap):
```
Я хочу с нуля освоить навык [НАЗВАНИЕ, например: копирайтинг]. Составь для меня жесткий 30-дневный план обучения по 30 минут в день. Напиши, что конкретно изучать каждую неделю и какие бесплатные ресурсы использовать.
```

## 3. Интерактивный тест-опрос:
```
Я хочу проверить свои знания по теме [ТЕМА]. Задавай мне по одному вопросу средней сложности по очереди. Я буду отвечать, а ты пиши, прав я или нет, исправляй ошибки и только потом задавай следующий вопрос.
```

## 4. Создание практического проекта:
```
Я изучил теорию по теме [ТЕМА]. Придумай для меня 3 простых практических проекта-задания, которые я могу сделать сам за выходные, чтобы закрепить навык на практике и положить результат в портфолио.
```

## 5. Поиск и исправление слепых зон:
```
Я считаю, что в теме [ТЕМА] главное - это [напиши свое понимание сути]. Действуй как строгий ментор. Найди в моем рассуждении логические ошибки или слепые зоны, о которых я даже не догадываюсь.
```
