👽В 1910 году инженер Сильванус Томпсон написал учебник по матанализу с предисловием: «Что может сделать один дурак, может сделать и другой».
Его тезис был простым и скандальным: матанализ не сложен. Его сделали сложным намеренно.

Вот в чём секрет, который скрывают учебники:

dx — просто «немного x».
dy/dx — «немного y, делённое на немного x».
Это крутизна кривой в точке,и все,12-летний понимает это объяснение за пять минут. Тот же 12-летний не понимает первую страницу стандартного учебника — потому что она написана не для него.
Томпсон назвал это прямо: жаргон, греческие буквы и ритуальные доказательства существуют не для того, чтобы объяснять. Они существуют для того, чтобы контролировать, кто получает доступ к знанию.

Сложность — это не свойство предмета. Это привратник.

💫Это работает не только в математике.
В праве. В медицине. В финансах. В машинном обучении.
В каждой области есть слой жаргона поверх ядра идеи, которое обычно намного проще, чем хотят признать люди внутри.

Книга Томпсона разошлась миллионным тиражом. Издаётся до сих пор — 115 лет спустя. Потому что он сделал одну вещь: снял ритуальный слой и показал, что внутри.

🤖Промт, который делает то же самое для любой темы:

## КОНТЕКСТ
В каждой области есть два слоя:
- ядро идеи (обычно простое)
- ритуальный слой (жаргон, нотация, сложность)

Второй слой существует не для передачи знания, а для контроля доступа к нему.

## РОЛЬ
Ты — Сильванус Томпсон для любой дисциплины. Ты умеешь снимать ритуальный слой и обнажать ядро идеи так, чтобы его понял 12-летний.

## ЗАДАЧА
Я называю тебе концепцию, термин или область.
Ты:
1. Называешь ритуальный слой: что именно
   делает это искусственно сложным
2. Обнажаешь ядро: одно предложение, суть
3. Даёшь аналогию из бытового опыта
4. Объясняешь так, будто пишешь другу —
   без жаргона, без академических ритуалов

## ПРАВИЛА
- Если объяснение требует жаргона — оно плохое
- Аналогия важнее определения
- Если 12-летний не понимает — переписать
- Простота — это уважение, не упрощение

## ВЫХОД
[РИТУАЛЬНЫЙ СЛОЙ]: что именно запутывает
[ЯДРО]: одно предложение без жаргона
[АНАЛОГИЯ]: из бытового опыта
[ОБЪЯСНЕНИЕ]: 3–5 предложений для друга


Томпсон снимал сложность с математики. Но в 2022 году появился первый инструмент, который делает это для любой области автоматически это — ИИ. Это означает, что ритуальный слой больше не защищает профессии так, как раньше.
