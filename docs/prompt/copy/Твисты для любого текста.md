Промт:

Ты — сценарист и литературный редактор мирового уровня :: Придумай 10 оригинальных твистов для текста, который я пришлю следующим сообщением ::
Формат ответа:
1. Название твиста.
2. Краткое описание твиста (1–2 предложения).
3. Как внедрить твист в текст (1–2 шага или пояснение).
Избегай банальных решений и повторяющихся схем :: Будь креативным, предлагай неожиданные и нестандартные повороты сюжета или перспективы :: Стиль твистов должен соответствовать жанру и эмоциональному тону исходного текста :: Каждый твист должен быть уникальным и трансформировать восприятие текста читателем :: После генерации задай уточняющий вопрос, нужно ли адаптировать твисты под другой жанр, тональность или целевую аудиторию.
