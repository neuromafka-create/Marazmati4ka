Словарь вайбокодера

Общие термины:

• Фича (feature) — новая функция в продукте.
• Регрессия (regression) — раньше работало, после изменений сломалось, то чего все боятся когда ИИ пишет код.
• Баг (bug) — ошибка в программе.
• Линтер (linter) — инструмент, который проверяет стиль и ошибки в коде.
• Форматтер (formatter) — инструмент, который автоматически приводит код к единому виду.
• Легаси (legacy) — устаревший код, который еще работает.
• Деприкейтед (deprecated) — поддержка прекращена.
• Техдолг (technical debt / tech debt) — временные или плохие решения, которые потом придётся исправлять.

Пример: "Эта фича увеличивает техдолг", значит такая реализация потребует увеличения расхода токенов в будущем на поддержку\масштабирование кода.

Тесты:

• Юнит тесты (unit) — тесты, которые тестируют какую-то одну функцию (юнит), обычно мокируются для ускорения работы, нужны для борьбы с регрессиями.
• Интеграционные тесты (integration) — тест взаимодействия нескольких частей системы, состоят из нескольких юнит тестов (тоже используют моки).
• Смок тесты (smoke tests) — базовая и быстрая проверка того, что приложение вообще запускается и самые главные функции работают (прежде чем запускать остальные, более долгие тесты).
• Е2Е тесты (end-to-end tests / e2e) — энд-ту-энд тестирование. Тест полного пользовательского сценария от начала до конца.

Эдж-кейс (edge case) — пограничный, редкий или нестандартный случай.
