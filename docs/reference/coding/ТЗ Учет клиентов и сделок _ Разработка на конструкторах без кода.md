# ТЗ Учет клиентов и сделок _ Разработка на конструкторах без кода

Требуется русскоязычноый разработчик для сборки простого MVP внутренней CRM для компании. Система нужна для учёта клиентов и сделок, с мобильной работой на iPhone. Нужно реализовать базу клиентов, сделки, статусы, 2 роли доступа и скрытие финансовых данных от менеджера. Рассматриваю Glide, AppSheet, Airtable/Softr и другие no-code решения.

Нужен no-code разработчик для MVP CRM / клиентской базы под iPhone

Система нужна для внутреннего использования на iPhone.

Это не сайт для клиентов, а рабочий инструмент для учёта клиентов и сделок внутри компании.

Что нужно сделать

Нужно собрать простую внутреннюю CRM, в которой можно:

• вести базу клиентов

• вести сделки

• менять статусы сделок

• назначать представителя

• назначать менеджера

• скрыть финансовые данные от менеджера

• автоматически считать прибыль по сделке

Основной функционал

1. Клиенты

В карточке клиента должны быть поля:

• ФИО

• телефон

• город

• дата обращения

• комментарий

Нужен список клиентов и удобный просмотр с телефона.

2. Сделки

В карточке сделки должны быть поля:

• клиент

• вид теста

• статус сделки

• представитель / партнёр

• менеджер

• цена продажи

• себестоимость

• комиссия представителю

• комиссия менеджеру

• прямые расходы

• возврат

• итоговая прибыль

3. Статусы сделки

Нужны базовые статусы:

• новая заявка

• в работе

• оплачено

• в лаборатории

• готово

• отказ

• возврат

4. Расчёт прибыли

Нужен автоматический расчёт по формуле:

прибыль по сделке = цена продажи – себестоимость – комиссия представителю – комиссия менеджеру – прямые расходы – возврат

Сложная бухгалтерия на этом этапе не нужна. Нужен именно базовый рабочий расчёт.

Роли доступа

Нужно настроить 2 роли:

1. Администратор

Полный доступ ко всем данным и всем полям.

2. Менеджер

Доступ ко всем клиентам и сделкам, но без доступа к финансовым данным.

Менеджер не должен видеть:

• цену продажи

• себестоимость

• комиссию представителю

• комиссию менеджеру

• итоговую прибыль

• финансовые итоги

Что важно

• приложение / система должна быть удобна для работы с iPhone

• интерфейс должен быть простой и понятный

• важно не только визуально собрать экраны, но и продумать логику учёта

• нужен именно MVP, без лишнего усложнения

Что НЕ нужно на первом этапе

На первом этапе не нужно:

• сложные автоматизации

• сложные дашборды

• бухгалтерские отчёты

• интеграции с внешними сервисами

• публикация в App Store

• сложный учёт общих расходов месяца

• многоуровневая система ролей

Какие платформы рассматриваю

Готова рассмотреть:

• Glide

• AppSheet

• Airtable / Softr

• другие подходящие no-code / low-code решения

Если вы считаете, что лучше делать на другой платформе, можно предложить свой вариант с пояснением почему.

Что хочу получить от исполнителя

• помощь в выборе оптимальной платформы

• сборку MVP

• настройку структуры данных

• настройку ролей доступа

• настройку базовых вычислений

• проверку, что всё корректно работает на iPhone
