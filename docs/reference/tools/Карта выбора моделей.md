# Зачем эта карта

Рынок ИИ-моделей перестал быть линейным. Сильнейшая модель не обязана быть

лучшей в чате, а самая дешевая — выгодной внутри продукта.

Поэтому это не рейтинг. Модель оценивается в связке: интерфейс + инструменты + цена

ошибки + стоимость результата. Одна и та же модель может быть избыточной на сайте,

идеальной в агенте и разорительной по API.

1
Среда

Сначала решаем, где работает модель: сайт, агент или API. От среды зависит все остальное.

2
Цена ошибки

Чем дороже переделка, тем сильнее должна быть модель и проверка результата.

3
Стоимость результата

Считаем не токен, а готовый документ, решение или действие.

Д Л Я К О Г О

Для тех, кто выбирает модель под сайт, агента или API и хочет платить за результат, а не за

бренд: предприниматели, продакты, разработчики и команды внедрения.

# Три среды: сайт, агент, API

Одна и та же модель дает разную ценность в зависимости от того, отвечает ли она в

чате, действует как цифровой сотрудник или обслуживает тысячи запросов внутри

продукта.

1
САЙТ — разговаривать

Пользователь ведет диалог сам. Ценность — удобство, качество ответа, файлы и быстрый

доступ.

2
АГЕНТ — делегировать

Модель получает цель, инструменты и материалы. Она планирует, действует и проверяет

результат.

3
API — встраивать

Модель скрыта внутри продукта. Важны цена на рубль, стабильность, формат ответа и

контроль.
