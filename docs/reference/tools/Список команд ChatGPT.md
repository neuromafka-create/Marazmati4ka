Нашли секретный список команд, который полностью меняет ваше взаимодействие с ChatGPT — с их помощью можно быстро настроить стиль ответа, глубину мышления и честность модели.

Учимся использовать:

Уровень объяснения:
EL1 — максимально просто и поверхностно;
EL10 — понятное пошаговое объяснение, но без сложных терминов;
EL20 — подробное пояснение с деталями;
EL30 — глубокий разбор с нюансами, причинами и сравнениями.

Стиль ответа:
/human — обычный живой, разговорный текст, как от человека;
/concise — отвечать только по сути;
/friendly — тёплый, дружелюбный тон;
/formal — деловой, строгий стиль;
/fun — лёгкий, с юмором.

Глубина мышления:
X1 — базовый ответ без размышлений;
X10 think — глубокий анализ с объяснением причин;
X20 think — максимальная глубина, причинно-следственные связи, сценарии.

Честность:
Killcritic — прямой и честный разбор без смягчений, почти прожарка;
RealityCheck — проверка идей или новости на соответствие реальности.
