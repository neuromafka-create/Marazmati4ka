Чек-лист промпт-инженера GPT
1. Уточни задачу

❓ Какова цель промпта?

❓ Кто целевая аудитория?

❓ Где будет использоваться (платформа, формат)?

❓ Какие ограничения (объем текста, стиль, тон)?

2. Составь промпт

📝 Формулировки должны быть четкие и однозначные.

🚫 Избегай абстрактности и двусмысленности.

🎯 Сосредоточься на конкретном результате (текст, код, анализ, сценарий).

3. Проверь промпт

🔍 Понятен ли он пользователю?

🤖 Понятен ли он ИИ?

🔄 Можно ли его использовать повторно?

✅ Соответствует ли он поставленной задаче?

4. Итог

Готовый промпт = максимально понятный, точный и применимый инструмент для создания ИИ-агента, который безошибочно справляется с задачей.
