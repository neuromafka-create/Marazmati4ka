# 4 сервиса для создания инфографики карточки товара ⬇️

Делюсь тем, чем пользуюсь сама. У них очень простой и удобный функционал.

🔹[**Supa**](https://supa.ru/)

Бесплатный российский аналог «Canva», с большим разнообразием шаблонов для создания карточек товара.

🔹[**WBCard**](https://wbcard.ru/)

Здесь много шаблонов и стоковых фотографий. Есть бесплатная версия, но с ограничениями по шрифтам. 

🔹[**Wondercard**](https://wondercard.ru/)  
(mb3678@vk.com	VSt5SFZj)

Этот сервис заточен под создание карточек для Wildberries и OZON. Есть бесплатный тариф с ограничениями.

🔹[**Desygner**](https://desygner.com/)

В этом сервисе можно создавать вообще все: начиная карточками товара и заканчивая резюме для работы.

Студенты нашей школы подробно изучают каждый сервис и сдают домашние задания до тех пор, пока мы не убедимся, что они точно разобрались.

---

Существует несколько нейросетей и инструментов, которые могут помочь в создании инфографики. Вот некоторые из них:

1. ***Canva*** - хотя это не нейросеть в чистом виде, Canva использует алгоритмы для упрощения дизайна и предлагает шаблоны, которые можно адаптировать для создания инфографики.

2. ***Visme*** - еще один инструмент для создания визуального контента, который использует технологии для автоматизации дизайна и предлагает множество шаблонов.

3. ***Piktochart*** - онлайн-платформа, которая помогает создавать инфографику с использованием шаблонов и простых в использовании инструментов.

4. ***Venngage*** - инструмент для создания инфографики, который также предлагает множество шаблонов и возможностей для настройки.

5. ***Datawrapper*** - инструмент для визуализации данных, который позволяет создавать графики и карты, которые могут быть использованы в инфографике.

6. ***DeepAI*** - предоставляет различные API, включая генерацию изображений, которые могут быть использованы для создания уникальных элементов дизайна.

7. ***DALL-E*** и ***Midjourney*** - нейросети для генерации изображений по текстовым описаниям, которые могут помочь в создании визуальных элементов для инфографики.

8. ***Artbreeder*** - платформа для совместного создания изображений с использованием **GAN**, которая может помочь в создании уникальных графических элементов.

Эти инструменты могут значительно упростить процесс создания инфографики, предоставляя пользователям возможность сосредоточиться на содержании и данных, а не на технических аспектах дизайна.
