## Gerwin

Это нейросеть, созданная специально
для русскоязычного сегмента интернета.

Она может генерировать тексты и изображения и работать

с уже существующими текстами (изменять их стиль,
сокращать, делать рерайт). Также Gerwin умеет адаптировать

сообщения под определенный стиль общения.

Продвинутые возможности:

Есть функциональный редактор,
типограф,

проверка орфографии,
автоматическое сохранение, история
сгенерированных текстов.

Для интеграции в другие онлайн-проекты
и для массовых генераций

предусмотрен
открытый API.

Примеры применения Gerwin:

Написание объемных статей, постов для соцсетей, отзывов,
комментариев;

Создание кликбейтных заголовков;

Создание характеристик товаров и описаний услуг;

Нейминг;

Создание продающих текстов, используя
известные маркетинговые модели AIDA, PAS, BAB;

Написание сценариев для видео.

Kandinsky (Fusion Brain) — бесплатная российская

и позы с загруженных картинок на сгенерированные.
