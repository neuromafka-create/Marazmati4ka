# Что такое Claude Code (и почему это не чат-бот)

Когда люди слышат «нейросеть», они представляют чат. Написал вопрос — получил
ответ.

Claude Code — другое. Это программа, которая работает прямо на твоём компьютере.
Видит файлы, запускает задачи, создаёт документы, отправляет письма. Не отвечает на
вопросы — делает работу.

Представь: ты нанял помощника, посадил его за свой компьютер и сказал
«разберись». Вот это Claude Code. Только помощник не спит, не ходит на обед и
работает круглые сутки.

Обычный чат-бот — позвонить эксперту и спросить совет. Claude Code — посадить
эксперта за свой стол и сказать: «Вот задача. Делай».

# Что он заменил

### Вместо ChatGPT

ChatGPT — хороший чат. Но чат. Ты спрашиваешь — он отвечает. Потом копируешь
ответ, вставляешь куда-то, переделываешь. Мартышкин труд.

Claude Code работает с файлами напрямую. Говоришь «напиши статью и сохрани в
такую-то папку» — он пишет и сохраняет. Не в окошко чата, а в реальный файл на
компьютере.

У Claude есть файл CLAUDE.md — в нём ты описываешь себя, свой бизнес, свой стиль.
Claude его читает каждый раз при запуске. Знает, кто ты, как ты пишешь, что тебе
важно. Не нужно объяснять заново.

Разница между случайным прохожим и ассистентом, который с тобой три года.

### Вместо генераторов картинок

Сам Claude не рисует. Но подключается к генераторам картинок и сам отправляет
запросы, получает результат, скачивает файл, вставляет куда надо. Без твоего участия.

Раньше: открой Midjourney, придумай запрос, подожди, скачай, переименуй, загрузи.
Сейчас: «сделай картинку для поста» — и она уже в нужной папке.

Notion AI работает только внутри Notion. А Claude Code работает с любыми файлами на
компьютере. Читает, пишет, редактирует — Word, текстовые файлы, таблицы. Без
промежуточных сервисов.

### Вместо Jasper, Copy.ai и прочих текстовых генераторов

Все эти сервисы генерируют тексты. Проблема — они не знают тебя. Каждый раз
заполняешь формочки: тон голоса, целевая аудитория, стиль.

Claude Code читает файл с описанием твоего голоса. Каждый текст — как будто ты сам
написал. Не «текст от нейросети», а твой текст.

Вот пример: фрилансер-копирайтер ведёт пять клиентов. Стиль у каждого разный.
Claude пишет пять вариантов одного поста — каждый под стиль конкретного клиента.
Не копипаст, а реальная адаптация.

### Вместо Zapier и Make

Zapier, Make — конструкторы автоматизаций. Соединяешь блоки: «когда пришло
письмо — отправь в таблицу — пришли уведомление». Удобно. Но ограничено.

Claude Code делает автоматизации напрямую. «Каждое утро в 9 собери новости по
моей теме и отправь в Telegram» — готово. Без конструктора, без лимитов на
количество операций.

### Вместо фрилансеров на рутину

Самый неочевидный пункт. Рутинные задачи, на которые раньше нанимали человека —
ресёрч, однотипные тексты, обработка таблиц — Claude делает за минуты.

Ты ищешь подрядчиков для проекта. Два дня ручного поиска. Или полчаса Claude — и
таблица с контактами, описаниями и ссылками готова.

Или нужно написать персональные письма двадцати потенциальным клиентам. Не
шаблон, а каждое — под конкретного человека. Claude изучает сайт компании,
понимает контекст и пишет письмо, которое не пахнет рассылкой.

### Шаг 2: Подключи к своим инструментам

Claude подключается к внешним сервисам через штуку под названием MCP. Звучит
сложно, на практике — просто.

Подключил к Telegram — Claude отправляет сообщения и получает команды.
Подключил к Google Sheets — записывает данные в таблицы. Подключил к браузеру —
заходит на сайты и делает там дела.

Для большинства задач хватит трёх-четырёх подключений: мессенджер, таблицы,
браузер, почта. И Claude умеет почти всё, что нужно для бизнеса.

### Шаг 3: Навыки — готовые суперспособности

У Claude Code есть «навыки» — готовые инструкции для конкретных задач. Как
приложения в телефоне, только для ИИ.

Можно собрать навыки под себя: копирайтинг, создание рилсов, рекламные креативы,
вебинарные сценарии. Каждый навык — файл с чёткими инструкциями: что делать, как
делать, какой результат.

Кидаешь тему — Claude сам выбирает нужный навык и делает. Не нужно объяснять
каждый раз.

### Шаг 4: Субагенты — Claude запускает других Claude

Когда задача большая, Claude сам запускает несколько помощников. Каждый работает
параллельно.

Пример: тебе нужно изучить тему перед запуском нового продукта. Claude запускает
четырёх субагентов — один ищет в вебе, второй на YouTube, третий в
Telegram-каналах, четвёртый на VC.ru. За двадцать минут — полная картина. Один
человек делал бы это два дня.

# Кейсы из жизни

### Автоматический контент на пять площадок

Один пост превращается в пять уникальных публикаций для разных соцсетей. Каждая
- адаптирована под формат площадки. Claude сам публикует, сам следит за
расписанием. Ты занимаешься стратегией, а рутину делает помощник.

Для фрилансера-SMM-щика, который ведёт несколько клиентов, это вообще спасение.
Раньше — ручной рерайт на каждую площадку. Сейчас — задал тему, получил готовые
посты.

### Холодные письма потенциальным клиентам

Ты фрилансер и ищешь новых клиентов. Claude находит компании в твоей нише,
изучает каждую — сайт, соцсети, последние новости — и пишет персональное письмо.
Не шаблонную рассылку, а письмо, из которого видно, что ты разобрался в бизнесе
получателя.

За полчаса — двадцать писем. Каждое уникальное. Попробуй нанять для этого
ассистента.

### Утренняя сводка трендов

Каждое утро в мессенджер приходит: актуальные темы из твоей области, вирусный
контент, готовые идеи для постов. Claude сам ищет по нужным источникам — Reddit,
YouTube, Telegram, VC.ru. Ничего не скроллишь — всё уже собрано и отсортировано.

Для контент-креатора или маркетолога — экономия часа-двух в день. Каждый день.

# Честно про ограничения

### Стоит денег

Claude Code Max — $200 в месяц. Для начала хватит Claude Pro за $20/мес, но без
безлимита. Для серьёзной работы нужен Max.

$200 — это цена одного фрилансера на пару задач. Claude заменяет нескольких. Но
если у тебя нет задач на автоматизацию — это выброшенные деньги. Не покупай
подписку «чтобы было».

### Нечёткая задача = плохой результат

Если задача размытая, Claude может ходить по кругу. «Сделай что-нибудь крутое» —
плохая задача. «Найди 30 компаний по теме X, изучи каждую, напиши персональное
письмо» — хорошая.

Чем конкретнее задача — тем лучше результат. Это не волшебная палочка, это
инструмент. Молотком тоже нужно уметь пользоваться.

### Не заменяет стратегию

Claude отлично делает тактику: найти, написать, опубликовать, проанализировать. Но
не скажет, какой бизнес открыть. Не придумает за тебя продукт. Не поймёт клиента
лучше тебя.

придумывай задачи для Claude — убирай задачи с себя.

# Почему один инструмент, а не пятнадцать

Каждый сервис делает что-то одно. Jasper пишет тексты. Midjourney рисует. Zapier
соединяет сервисы. Notion хранит заметки.

Проблема: они не разговаривают друг с другом. Ты — единственное связующее звено.
Копируешь текст из Jasper в Notion, скачиваешь картинку из Midjourney и загружаешь в
Canva, настраиваешь цепочку в Zapier.

Claude Code — один инструмент, который умеет всё вместе. Пишет текст, вставляет
картинку, публикует, анализирует результат. Всё в одном месте, всё связано.

Не потому что Claude лучший в каждой отдельной задаче. А потому что один
инструмент, который растёт вместе с тобой — сильнее пятнадцати, которые не знают
друг о друге.

Файл CLAUDE.md накапливает контекст. Каждый новый навык, каждое новое
подключение — делает помощника сильнее. Через месяц он работает лучше, чем в
первый день. Через полгода — в разы лучше.

Ни один из пятнадцати отдельных сервисов так не умеет. Они не помнят тебя. Не
учатся. Не связываются.
