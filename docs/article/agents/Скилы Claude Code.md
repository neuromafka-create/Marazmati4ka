🔘 Что такое скилы Claude Code - разбираем все четыре уровня

Все говорят про скилы Claude Code. Репозитории летят в чаты, кто-то что-то подключает, восхищается, и складывается ощущение что нужно срочно всё установить себе, иначе пролетишь.

На деле путаница возникает потому что одним словом называют четыре принципиально разные вещи.

▶️CLAUDE.md - это память Claude. Файл на вашем компьютере, который он читает при каждом запуске. Ваши правила, контекст проектов, технические запреты. Именно здесь живёт то, что вы устали повторять каждую сессию заново.

▶️Официальные скилы - готовые способности от Anthropic. Создать Word-документ, Excel-таблицу, презентацию, PDF. Если вы пользуетесь Claude.ai в браузере - они уже работают, ничего настраивать не нужно. Для терминала скачивать тут (http://github.com/anthropics/skills). Там же открытый стандарт как писать свои.

▶️Пользовательские скилы - чужой опыт, упакованный в текстовый файл. Любой человек может написать инструкцию "как делать X" и выложить на GitHub. Брать можно, но не всё подряд — иначе станет только хуже.

Чтобы не искать самостоятельно по GitHub, есть готовые каталоги:
awesome-claude-code (http://github.com/hesreallyhim/awesome-claude-code) -  качественная подборка, отобранная вручную. Скилы, хуки, плагины, агенты.
awesome-claude-skills (http://github.com/travisvn/awesome-claude-skills) - каталог скилов с описаниями и категориями, удобно для поиска нужного.
awesome-agent-skills (http://github.com/VoltAgent/awesome-agent-skills) - большой репозиторий, совместим с Claude Code, Cursor, Gemini CLI и другими.
skillsmp.com — сайт, где можно искать скилы по категориям, не копаясь в GitHub.

▶️MCP-серверы - это уже другой уровень. Не знания и инструкции, а реальные подключения к внешним сервисам. Через MCP Claude не просто знает про ваш проект — он его использует. Про это надо отдельно и подробно.
