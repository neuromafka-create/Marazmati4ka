# Задачи_с_помощью_ИИ_—_сводный_отчёт

**ЗАДАЧИ, КОТОРЫЕ ЛЮДИ РЕШАЮТ С ПОМОЩЬЮ ИИ**

*Сводный отчёт по 8 потокам курсов + расширенный анализ ниш «Руководители» и «Производство/Машиностроение»*

*Источники: Telegram-чаты потоков AI-навигатор, ИИ-маркетолог, Интенсив Claude AI для CFO и др.*

**1. ФИНАНСЫ: CFO, финансовые директора, аналитики, бухгалтеры**

*Участники курсов: финансовые директора (10–15+ лет стажа), руководители FPA и контроллинга, финансовые аналитики, инвест-директора, главные бухгалтеры.*

| Задача | Профессия / ниша |
| --- | --- |
| Построение многомерных финансовых моделей | Финдир / CFO |

| Составление ОДДС косвенным методом по РСБУ на основе ОСВ | Финансовый директор |
| Анализ план-факта с рекомендациями по корректировке | CFO / FPA |
| Факторный анализ отклонений | Финансовый аналитик |
| Оценка инвестиционной привлекательности объекта (due diligence) | CFO / инвест-директор |
| Дашборд рентабельности сделок с цветовой сигнализацией (RAG) | Финансовый директор |
| Анализ операционных данных (1500+ строк CSV) | CFO / стартап |
| Написание регламентов финансовых бизнес-процессов | CFO |
| Подготовка материалов к совету директоров | CFO |
| Бюджетирование, прогнозирование cash flow, P&L через ИИ | CFO / FPA |
| Анализ договоров и финансовой отчётности | CFO / юрфин |
| Интеграция ИИ в 1С (чат-бот для платёжных поручений) | Финдир / IT |
| ИИ-помощник в роли финансового директора | Директор компании без штатного CFO |

| Проверка контрагентов и анализ тендеров | CFO / закупки |
| Расшифровка тендерной документации | CFO / тендерный отдел |
| Мониторинг изменений в финансовом законодательстве | CFO / главбух |

| Расчёт юнит-экономики и выявление проблемных точек | CFO / стартап |
