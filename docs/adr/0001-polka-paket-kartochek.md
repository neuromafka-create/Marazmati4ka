# Полка — пакет карточек, библиотека остаётся блокнотом

Обмен наборами карточек между блокнотами делаем полкой-файлом. Её вливают копией в свою библиотеку. Экран «Библиотека» не переименовываем: это по-прежнему один блокнот с одной базой.

Отклонённый вариант — назвать нынешний корень полкой, а библиотекой набор таких папок. Слово «библиотека» уже стоит на единственном домашнем экране. Целая папка данных ещё и не то, чем делятся: в ней ключ Hubris, корзина и настройки. У человека с одним блокнотом внешний уровень «библиотека из одной полки» ничего не добавляет.

Живую чужую папку, которая обновляется сама, отложили. Для неё пришлось бы искать сразу по двум базам и мирить совпадающие коды областей. Учётные записи не делаем: программа для одного человека на своей машине.

Две установки, Marazmati4ka и Склерозник, остаются двумя библиотеками. Полка переносит между ними набор карточек, не весь профиль. План работ — в [DESIGN.md](../../DESIGN.md), раздел «Дальше: полки».
