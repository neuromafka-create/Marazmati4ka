# Changelog

## 0.2.0 — 2026-08-15

### Added

- Панель форматирования в редакторе: инлайн и блоки, предпросмотр «Как будет»
- В увеличенном просмотре нескольких картинок — стрелки, ←/→ и счётчик
- Смена роли уже прикреплённой картинки
- Настройки: подключение Hubris, проверка связи, генерация иллюстрации
- Референсы к промпту иллюстрации (файл, Ctrl+V, «Из записи») — по умолчанию пусто
- Удаление записи с карточки библиотеки
- Windows-инсталлятор Marazmati4ka (`npm run desktop`)
- Пустой установщик «Склерозник» (`npm run desktop:empty`): своя папка данных, порт 3007, универсальные типы и области

### Fixed

- Ctrl+V больше не дублирует скриншот (PNG+BMP / items+files)
- В установщик не попадал `node_modules` сервера — приложение сразу падало
- При закрытии окна показывалась ложная ошибка `4294967295`

## 0.1.0 — 2026-08-15

Первая публичная версия блокнота.

### Added

- Библиотека, просмотр, создание, правка, корзина
- Поиск, фильтры по типу и области, сортировка
- Несколько областей на одну запись
- Справочники типов и областей
- Картинки: файл, Ctrl+V, крестик, lightbox
- Блоки кода с переносом, языком и копированием
- Импорт `docs/` в SQLite при первом запуске
- Тёмная графитовая тема и светлая
